slang/grammar

slang/grammar: the slang grammar, built with slang/peg on top of a rule registry that lets programs extend and modify the parser at compile time. An extension gets the grammar of the unit being compiled with require("slang/compiler").grammar() and changes it from an extension statement; the change applies from the next top-level statement on.

extension {
  local peg = require("slang/peg")
  local g = require("slang/compiler").grammar()
  // unless(condition){ ... }
  g:statement("unless", peg.seq(
    g:keyword("unless"), g:token("("), g:rule("expr"), g:token(")"),
    g:rule("block"),
  ):map(func(r){
    return {token: r[0], ast: +{stat: if(not -{r[2]}) -{r[4]}}}
  }))
  // x |> f calls f(x); looser than every core operator
  g:expression():level("pipe", {after: "or"}):left(
    g:token("|>", null, "operator"), func(left, op, right){
      return {token: op, ast: +{-{right}(-{left})}}
    },
  )
}
unless(1 > 2){
  print(16 |> string, "\n")
}

Parsers come from slang/peg; tokens from Grammar.token and Grammar.keyword skip the whitespace and comments around them. What an extension's parser or callback produces is Code: an AST node (see slang/ast), usually from a quote, with the token it should be reported at. Grammar changes are only allowed between top-level statements (from an extension statement) or at run time, never while a statement is being parsed.

A grammar is a registry of named rules plus the registries of statements, extension statements and the expression walker (primaries, levels and operators, see peg.walker). Rules are referenced by name (g:rule(name)) and resolved late: the first parse after a change seals the grammar (builds the expression walker, the dispatch tables and the rule targets) once. Grammars derive from each other; the rule references are shared by a whole lineage and always point at the rules of the grammar that was activated last.

parsing

grammar.comments(buffer: string, start: int, stop: int) -> {{category: string, start: int, stop: int}}

The // comments in buffer[start, stop), a run of trivia, as highlighter spans of category "comment" (see peg.highlights).

grammar.new(opts?: Options) -> Grammar

The root grammar of a new lineage, with slang's syntax. Extensions do not call it: they get their grammar from the compiler (see the module doc).

type Code

type Code = ast.Node | {token: peg.Token, ast: ast.Node}

What extension parsers and callbacks produce: a node, or a node with the token it came from, which every node of it without a token gets (so errors in generated code point at the source; see ast.decode).

type Options

type Options = {run_block?: func(block: ast.Node): any, run_extension?: func(node: ast.Node, origin: string), optimize?: func(block: ast.Node): ast.Node, warn?: func(message: string, owner: string), explain?: func(origin: string, unit: Grammar), memoize?: bool}

The options of a root grammar (new); the compiler passes them.

run_block?: func(block: ast.Node): any
executes an unquote at parse time
run_extension?: func(node: ast.Node, origin: string)
runs a built-in extension statement (a file name or a block)
optimize?: func(block: ast.Node): ast.Node
applied to every parsed chunk
warn?: func(message: string, owner: string)
reports grammar warnings; with it set, modify checks shapes and probes
explain?: func(origin: string, unit: Grammar)
called after a unit parsed under a grammar of its own
memoize?: bool
false turns off the memoization placed while sealing

type RuleOptions

type RuleOptions = {protected?: bool, probe?: string, build?: func(g: Grammar): peg.Parser}

The options of Grammar.define.

protected?: bool
modify raises for this rule
probe?: string
source the rule must keep parsing; checked after every modify while warnings are on
build?: func(g: Grammar): peg.Parser
builds the rule at seal time instead (define it with parser null)

type Grammar

A grammar: the rules, statements and expressions of slang for one unit (a file or a compiled string), as extensions see it. Derived grammars share their rule references (see Grammar.derive).

Grammar:changes_allowed() -> bool

Whether the grammar may be changed now: at run time (no parse in progress), or from an extension statement between two top-level statements. The methods that change it raise otherwise.

Grammar:rule(name: string) -> peg.Parser

A parser for the rule of that name, resolved at parse time: it always parses the rule as the grammar in use defines it, modifications made later included. Core rules include "expr", "statement", "block", "chunk", "identifier", "param", "slang_pattern", "table_literal", "string_literal" and "trivia"; Grammar.rules lists them all.

Grammar:define(name: string, parser: peg.Parser?, options?: RuleOptions)

Registers a rule, replacing one of the same name. A rule may also be built at seal time: define(name, null, {build: func(g){ ... }}). Raises when changes are not allowed (see Grammar.changes_allowed).

Grammar:modify(name: string, f: func(old: peg.Parser): peg.Parser)

Replaces the rule by f(old), where old is its current parser; replacing it outright is just not using old. Rules built at seal time ("expr", "statement") are wrapped after building, so f runs at seal time: create the tokens it uses before calling modify. Raises for an unknown or protected rule, and when f does not return a parser.

g:modify("identifier", func(old){
  return old:where(func(t){ return t.value != "it" }, "not it")
})

Grammar:rules() -> {RuleInfo}

returns
every rule with where it came from, in order

Grammar:derive() -> Grammar

A grammar that starts as a copy of this one; changes to either do not affect the other. The unit grammars are derived from the root this way.

Grammar:root() -> Grammar

The root grammar of the lineage: slang plus the ambient layer (the project's extensions).

Grammar:unit() -> Grammar

The grammar of the unit being parsed; this one at run time.

Grammar:has_extension(name: string) -> bool

Whether the extension was loaded into this grammar (or the one it was derived from).

Grammar:add_extension(name: string)

Records that the extension was loaded into this grammar; the compiler calls it.

Grammar:extensions() -> {string}

returns
the extensions loaded into this grammar, in order

Grammar:with_owner(owner: string, f: func(): any) -> any

Runs f with the grammar changes it makes attributed to owner (for Grammar.rules and warnings) and returns what f returns.

Grammar:keyword(s: string) -> peg.Parser

A token parser for the word s, which becomes reserved: no longer an identifier, though still usable as a field name (t.unless). Its value is a peg.Token. Reserving a new word is a grammar change.

Grammar:token(source: string | peg.Parser, name?: string, category?: string) -> peg.Parser

A token trimmed by trivia (whitespace and comments); its value is a peg.Token. Unlike Grammar.keyword, a word given here is not reserved.

source
the token's text (a word may not be followed by an identifier character), or a parser whose text makes the token
name
what the failure message says is expected
category
what a highlighter shows: by default "keyword" for words, "punctuation" for other strings, name for parsers g:token("=>") g:token(peg.digit():plus(), "number", "number")

Grammar:tag(parser: peg.Parser, category: string) -> peg.Parser

What parser produced, highlighted again under category without changing its value (see peg.tag).

g:tag(g:rule("identifier"), "function.declaration")

Grammar:unit_id() -> int

A number identifying the parse of the current unit (a new one for every unit, nested compiles included), for per-unit state in an extension loaded once for a whole project.

Grammar:origin() -> string?

returns
the name of the source being parsed (null outside a parse)

Grammar:unit_local(key: string, expr: ast.Node) -> ast.Node

An Identifier for a local of the unit being parsed, declared once per unit as local <name> = expr, before the top-level statement that first asked for it. For the code an extension generates in expression position, where it cannot declare anything: a runtime module is required once per unit instead of at every use. The name is __ and key with every other character replaced by _. Raises outside a parse.

local async = g:unit_local("slang/async", +{require("slang/async")})
return {token: op, ast: +{-{async}.await(-{exp})}}

Grammar:error_at(token: peg.Token, ...message)

Raises a compile error located at token (a token as Grammar.token and Grammar.keyword produce, or any table with line and column), with the parts of message joined.

Grammar:uniq_id() -> ast.Node

An Identifier node with a fresh name no program can write, for the locals of generated code.

Grammar:expression() -> ExpressionRegistry

The expression registry of the grammar: where primaries, levels and operators are added.

Grammar:seal()

Builds the rule targets, the expression walker and the dispatch tables of this grammar; the first parse after a change does it. Rules built at seal time (expr, statement, extension_statement) are built in that order, each installed before the next is analysed, so first sets never come from a stale definition.

Grammar:activate()

Makes this grammar the one the rule references parse with, sealing it first when it changed.

Grammar:statement(name: string, parser: peg.Parser)

Adds a statement (or replaces the one of that name); parser yields Code for a statement node. Statements are tried in the order they were added, before slang's own statements.

Grammar:extension_statement(name: string, parser: peg.Parser, apply: func(result, g: Grammar): Code?)

A statement that is only recognised at the top level. After it parsed, apply(result, g) runs between statements with grammar changes allowed, with result parser's value and g the grammar of the unit being parsed (not necessarily this one: a project loads an extension once), and returns the statement to emit, or null.

Grammar:walker() -> peg.Walker

A fresh expression walker skipping slang trivia, for extensions that define their own expression language (see peg.walker).

Grammar:run_extension(parsed: table, origin: string) -> ast.Node?

Runs a parsed extension statement (what the "extension_statement" rule produced) and returns the statement node to emit, or null; the parser of a unit calls it between top-level statements.

Grammar:parse_source(source: string, origin: string, options?: {scoped?: bool, tree?: bool, recover?: bool, sandbox?: bool}) -> ast.Node

Parses a unit to a Block node, one top-level statement at a time, running its unquotes and extension statements. Raises on failure; the details of a parse failure are in g.state.last_failure ({message, pos, far_pos, far_message}).

Grammar:parse_repl(source: string) -> ast.Node

A chunk, or an expression wrapped in a Return. The REPL is one unit spread over many lines: its extension statements are not scoped.

type ExpressionRegistry

The expression registry of a grammar (Grammar.expression): its expression walker (see peg.walker) behind a facade that decodes what extension callbacks return (Code). Levels are ordered tightest first; core has "bracket", "indexAndCall", "power", "unary", "multiply", "add", "shift", "bitAnd", "bitXor", "bitOr", "compare", "and" and "or". Its changes are grammar changes. Operators of one level are tried in the order they were added.

ExpressionRegistry:primary(name: string, parser: peg.Parser, placement?: peg.Placement) -> ExpressionRegistry

Adds a primary expression: what an operand can be. parser yields Code. Note the order of the arguments: peg's walker takes the parser first.

ExpressionRegistry:level(name: string, placement?: peg.Placement) -> Level

A new precedence level placed among the others (without a placement: looser than all). A level of a name already in use is replaced by the new, empty one.

g:expression():level("pipe", {after: "or"})

ExpressionRegistry:prefix(operator: peg.Parser, level: string, callback: func(op: peg.Token, operand: ast.Node): Code) -> ExpressionRegistry

A prefix operator at the level of that name.

ExpressionRegistry:postfix(operator: peg.Parser, level: string, callback: func(left: ast.Node, op: peg.Token): Code) -> ExpressionRegistry

A postfix operator at the level of that name.

ExpressionRegistry:left(operator: peg.Parser, level: string, callback: func(left: ast.Node, op: peg.Token, right: ast.Node): Code) -> ExpressionRegistry

A left-associative infix operator at the level of that name.

ExpressionRegistry:right(operator: peg.Parser, level: string, callback: func(left: ast.Node, op: peg.Token, right: ast.Node): Code) -> ExpressionRegistry

A right-associative infix operator at the level of that name.

ExpressionRegistry:wrapper(left: peg.Parser, right: peg.Parser, level: string, callback: func(left: peg.Token, value: ast.Node, right: peg.Token): Code) -> ExpressionRegistry

An expression between two tokens, such as parentheses, at the level of that name.

ExpressionRegistry:nud(operator: peg.Parser, rbp: int, f: func(w: peg.Walker, ctx: peg.Context, pos: int, op): int) -> ExpressionRegistry

Engine API, for syntax that must act before its operand is parsed: an operator an expression starts with, at an explicit binding power. f parses its own operands through w:parse_at(ctx, pos, bp), leaves an AST node in ctx.value (it is not decoded) and returns the new position or -1 (see peg.walker).

ExpressionRegistry:led(operator: peg.Parser, lbp: int, f: func(w: peg.Walker, ctx: peg.Context, pos: int, left, op): int) -> ExpressionRegistry

Engine API: an operator that follows a value, as for ExpressionRegistry.nud.

ExpressionRegistry:levels() -> {string}

returns
the names of the levels, tightest first

ExpressionRegistry:primaries() -> {string}

returns
the names of the primary expressions, in order

type Level

A level of an ExpressionRegistry, as ExpressionRegistry.level returns it: adds operators at that level. Each method returns the level.

Level:prefix(operator: peg.Parser, callback: func(op: peg.Token, operand: ast.Node): Code) -> Level

ExpressionRegistry.prefix at this level.

Level:postfix(operator: peg.Parser, callback: func(left: ast.Node, op: peg.Token): Code) -> Level

ExpressionRegistry.postfix at this level.

Level:left(operator: peg.Parser, callback: func(left: ast.Node, op: peg.Token, right: ast.Node): Code) -> Level

ExpressionRegistry.left at this level.

Level:right(operator: peg.Parser, callback: func(left: ast.Node, op: peg.Token, right: ast.Node): Code) -> Level

ExpressionRegistry.right at this level.

Level:wrapper(left: peg.Parser, right: peg.Parser, callback: func(left: peg.Token, value: ast.Node, right: peg.Token): Code) -> Level

ExpressionRegistry.wrapper at this level.
