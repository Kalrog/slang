files

m.exists(path)

exists(path) -> whether a file or directory exists at path

m.is_dir(path)

is_dir(path) -> whether path is a directory

m.read_file(path)

read_file(path) -> the whole content of the file as a string. Raises an error when it cannot be read.

m.write_file(path, content)

write_file(path, content): writes the string content to the file, replacing what was there. Raises an error when it cannot be written.

m.list_dir(path)

list_dir(path) -> the sorted list of the names of the entries of the directory. Raises an error when it cannot be listed.

m.mkdir_all(path)

mkdir_all(path): creates the directory and any missing parents. Raises an error when it cannot.

process

m.cwd()

cwd() -> the current directory

m.getenv(name)

getenv(name) -> the value of the environment variable, or null

m.write_stderr(text)

write_stderr(text): writes text to standard error, after flushing standard output

m.exit(code)

exit([code]): flushes standard output and ends the process with code (0 by default)

clocks

m.clock()

clock() -> seconds since the program started, as a double (monotonic)

m.time_ms()

time_ms() -> milliseconds since the Unix epoch, as an int

programs

m.exec(argv, cwd)

exec(argv, [cwd]) -> {status, stdout, stderr}: runs a program (argv[0], looked up on the PATH) in cwd and waits for it; status is its exit code, -1 when a signal ended it. Raises when it cannot be started. Blocking, for tools; slang/async's exec does not block.

m.platform()

platform() -> "<os>-<arch>" of the running slang, as Zig names them ("macos-aarch64", "linux-x86_64"): where packages keep their prebuilt native modules (lib/<platform>/)
