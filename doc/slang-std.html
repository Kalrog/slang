module(mfunc)

module{ ... } runs the block with a fresh environment table as its _ENV, so that every global defined inside ends up in that table.

__match(m, v)

__match(m, v): the matcher protocol behind 'm patterns: m's __match metamethod decides whether v matches (null: no) and what the rest of the pattern sees (anything else)

run(rfunc)

run{ ... } evaluates a block as an expression.
