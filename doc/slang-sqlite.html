slang/sqlite

slang/sqlite: SQLite with an API that reads well, on the native sqlite extension. The sql{ ... } literals of extensions/sqlite make the queries; plain SQL text with a list of values works as well.

local db = sqlite.open("todos.db")            // or ":memory:"
db:exec("create table if not exists todos(id integer primary key, text text, done boolean)")
db:run(sql{ insert into todos(text, done) values ({text}, {false}) })  // {changes, last_id}
db:all(sql{ select * from todos where done = {done} })  // rows, tables by column name
db:one(sql{ select * from todos where id = {id} })      // a row or null
for(let {id: local id, text: local text} in db:each(sql{ select id, text from todos })){ ... }
db:transaction(func(){ ... })   // commits, or rolls back when the function raises
db:all("select * from todos where id > ?", {5})          // the same without the syntax
db:close()

A query (Query) is SQL text with one ? per value, and the values. A value made with list expands to ?, ?, ... and a value that is itself a query is spliced in with its parameters, so fragments compose safely. Values are null, bools (stored as 0/1), ints, doubles and strings; a column declared boolean reads back as true/false. Prepared statements are cached per database by text. Errors raise "sqlite: ..." naming the literal: "sqlite: no such table: todo (at views.slang:12)".

sqlite.version() -> string

The version of the SQLite library.

queries

sqlite.list(items: {any}) -> table

A value for a query that expands to one ? per item, for in (...); an empty list expands to null, which matches nothing.

db:all(sql{ select * from todos where id in ({sqlite.list(ids)}) })

sqlite.query(text: string, values?: {any}, origin?: string, count?: int) -> Query

A query of text with one ? per value; list values and queries among the values are expanded into the text. Raises when the number of ? does not match (a ? in a string, a quoted name or a comment is not counted).

origin
where the query comes from, added to its error messages
count
how many values (len(values)); a null value ends a list's length

databases

sqlite.open(path: string) -> Database

Opens a database file, created when missing; ":memory:" opens one in memory. Raises when it cannot be opened.

text: string

type Row

type Row = {[string]: any}

A row: its values by column name.

type RunResult

type RunResult = {changes: int, last_id: int}

What Database.run tells about a statement that changed rows.

changes: int
the number of rows inserted, updated or deleted
last_id: int
the rowid of the last inserted row

type Database

An open database, from open.

Database:all(q: Query | string, values?: {any}) -> {Row}

The rows a query returns. q is a query, or SQL text with values for its ? (as for all of these methods).

Database:one(q: Query | string, values?: {any}) -> Row?

The first row a query returns, or null.

Database:run(q: Query | string, values?: {any}) -> RunResult

Runs a statement to the end, ignoring rows: an insert, update or delete.

Database:each(q: Query | string, values?: {any}) -> func(): Row?

An iterator of the rows, for for(let row in db:each(q)), reading one row at a time. The loop has a statement of its own, so the loop's body may run any query, the same one included; the statement is finalized when the rows end (or when a loop left early is collected).

Database:all_async(q: Query | string, values?: {any}) -> async.Future

Database.all on the thread pool: a Future of the rows.

Database:one_async(q: Query | string, values?: {any}) -> async.Future

Database.one on the thread pool: a Future of the first row or null. The query runs to the end: give it a limit.

Database:run_async(q: Query | string, values?: {any}) -> async.Future

Database.run on the thread pool: a Future of a RunResult.

Database:exec(q: Query | string)

Runs one or more statements, without parameters or results: schema changes, pragmas.

Database:transaction(f: function)

Runs f in a transaction: commits when it returns, rolls back and raises the error again when it raises. Transactions do not nest.

returns
what f returns

Database:close()

Finalizes the cached statements and closes the database; raises while an _async query is running.
