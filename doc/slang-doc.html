slang/doc

slang/doc: API documentation from the comments the code already has, as HTML: slang doc [-o dir] [file|dir...].

slang doc -o site/api slang/lib/http.slang

A module is a file that returns a table; its documentation is the comment block that starts the file and, for every field of the returned table, the comment just above its definition (no blank line between). Section dividers (// ---- title) group the fields. In a comment, lines indented by two or more spaces are code samples; the rest is prose. A file that returns no table is documented by its globals that have a comment (the stub of the globals); others (programs, tests) are left out.

A doc may start with a typed signature, describe parameters and fields in [name]: text lines and refer to names as [name]; files declare types in // type Name = ... lines (the notation is slang/symbols'). Signatures and types are shown with their names linked, and every type gets a section: a declared one with its fields or methods, and a meta table with __index and __type with its methods.

Native modules and the globals are documented from their stubs (see compiler.stub_path). Without paths: the project in the working directory (a slang.project there), else slang's own library with the stubs. Output goes to dir (./doc by default): index.html and a page per module (slang/http is slang-http.html).

modules

doc.module(name: string, path: string, source: string, index?: symbols.Index) -> ModulePage?

A module's documentation: the fields of the table the file returns (or, in a file that returns none, its documented globals), by section, then its types; null when there is nothing to document.

source
the file's text (not read: index has what is needed)
index
the file's names (compiler.highlight with symbols)

doc.module_body(m: ModulePage) -> string

The module's documentation as HTML, without the page around it (for a site with a layout of its own): its title, doc, table of contents and entries.

doc.module_html(m: ModulePage) -> string

returns
the module's page, as HTML

doc.index_body(modules: {ModulePage}, title: string) -> string

The index as HTML without the page around it: each module, linked to its page, with the first sentence of its doc.

doc.index_html(modules: {ModulePage}, title: string) -> string

The index page: each module with the first sentence of its doc.

doc.page_name(module: string) -> string

The file of a module's page: slang/http is slang-http.html.

doc.blocks_html(text: string) -> string

Doc text as HTML: paragraphs with code spans, and lines indented by two spaces or more as code samples.

the command

doc.main(arguments: {string}) -> int

slang doc [-o dir] [file|dir...]: documents the .slang files found. A file that does not parse is reported and the exit code is 1.

returns
the exit code

doc.collect(paths: {string}) -> {modules: {ModulePage}, status: int}

The modules of the .slang files in paths (files, or directories searched all the way down), sorted by name. A file that does not parse is reported on stderr and makes status 1.

type ModulePage

type ModulePage = {name: string, path: string, doc?: string, sections: {PageSection}, links: Links}

The documentation of a module, as module gathers it.

name: string
the module's name, as require takes it
path: string
the file, as shown
doc?: string
the module's doc, the comment block that starts the file
sections: {PageSection}
links: Links

type PageSection

type PageSection = {title?: string, defs: {Entry}, type_name?: string, decl?: symbols.TypeDecl}

A part of a page: the entries under a section divider (title null for those before the first), or a type with its methods.

title?: string
defs: {Entry}
type_name?: string
set for a type's section
decl?: symbols.TypeDecl
the declaration, for a type the doc comments declare

type Entry

type Entry = {name: string, signature: string, doc?: string, start?: int, info: symbols.DocInfo, params?: {string}, method?: bool}

A documented definition.

name: string
its anchor on the page ("Type:name" for a method)
signature: string
from its parameter names, for a doc without a typed one
doc?: string
start?: int
info: symbols.DocInfo
params?: {string}
method?: bool

type Links

type Links = {types: {[string]: bool}, exports: {[string]: bool}, aliases: {[string]: string}, methods: {[string]: bool}}

What names in a page's docs can link to.

types: {[string]: bool}
the module's types
exports: {[string]: bool}
the module's documented fields
aliases: {[string]: string}
the locals that hold a module, and its name
methods: {[string]: bool}
the anchors of the types' methods ("Type:name")
