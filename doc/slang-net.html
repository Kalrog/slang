slang/net

slang/net: networking for games. A server and its clients exchange messages over UDP: named messages with a table of data each, sent reliably (resent until they arrive, in order), unreliably (fire and forget, for what is out of date soon anyway) or sequenced (unreliable, and an older one of the same name is dropped once a newer one arrived).

local net = require("slang/net")
local server = net.server({port: 7777})
server:on("connect", func(peer){ peer:send("welcome", {id: peer.id}) })
server:on("move", func(peer, m){ players[peer.id].x = m.x })
server:on("disconnect", func(peer, reason){ delete(players, peer.id) })

local client = net.connect("127.0.0.1", 7777)
client:on("welcome", func(m){ my_id = m.id })
client:send("move", {x: 3}, {mode: "unreliable"})

for(not rl.window_should_close()){
  server:poll()      // receive, run the handlers, send what is queued
  client:poll()
  ...
}

Nothing happens behind the program's back: messages arrive, handlers run and queued messages go out in Server.poll and Client.poll, which a game calls once per frame. A server without a frame loop calls Server.run instead. Code that runs inside slang/async (or uv.run) may poll too: the loop is running already, so poll only handles what arrived.

A Protocol names the messages up front and the fields of each, so that a message travels as its number and its values without the field names; both sides must use the same one (a client with another is turned away). Without one, a message travels with its name and its whole table.

Message data is anything slang/encoding's binary form takes: null, booleans, numbers, strings and tables of them. A reliable message may be large (it is split into packets); an unreliable one must fit in one packet (max_unreliable bytes encoded).

options.simulate makes a host's network worse on purpose, to see how a game plays with lag and loss: every packet it sends or receives is delayed by latency ms plus up to jitter ms (so packets also overtake each other), and dropped with the probability loss.

There is no encryption or authentication: anyone who can reach the port can connect, and a peer's messages are what it chose to send. Servers check what clients tell them.

net.max_unreliable

max_unreliable: the largest unreliable or sequenced message, encoded

protocols

net.protocol(definition: {name: string, messages: {string: {string} | string}}) -> Protocol

A protocol: definition.messages maps each message name to the list of its fields, or to "any" for a message whose data travels whole (a list, say, or a table whose keys vary). Fields that are null are left out.

net.protocol({name: "arena", messages: {
  move: {"dx", "dy"}, chat: {"text"}, state: "any",
}})

servers

net.server(options?: ServerOptions) -> Server

A server, listening right away. Its handlers (Server.on) run in Server.poll: "connect" gets the Peer, "disconnect" the peer and the reason, a message the peer and its data.

clients

net.connect(host: string, port: int, options?: ConnectOptions) -> Client

A client connecting to a server; host is an IP address or a name to look up. Its handlers (Client.on) run in Client.poll: "connect" with nothing once the server accepted it, "disconnect" with the reason (when it could not connect too), a message with its data. Messages sent before it is connected wait.

The messages a server and its clients exchange: protocol makes one.

the name it was made with

the name and every message with its fields, as text; a client is accepted only with the server's signature

type SendOptions

type SendOptions = {mode?: string}

How a message goes. Reliable messages arrive once each, in the order they were sent; unreliable ones may not arrive, or twice never but out of order; sequenced ones like unreliable, minus any older than the newest of the same name that arrived.

mode?: string
"reliable" (the default), "unreliable" or "sequenced"

type ServerOptions

type ServerOptions = {port?: int, host?: string, protocol?: Protocol, max_peers?: int, timeout?: number, simulate?: Simulate}

Options of server.

port?: int
the UDP port (0, the default, picks a free one)
host?: string
the address to listen on, "0.0.0.0" (every IPv4 one) by default
protocol?: Protocol
the messages; without one, names and whole tables travel
max_peers?: int
more clients are turned away ("server full"), 32 by default
timeout?: number
a client not heard from for this many ms is gone (5000)
simulate?: Simulate
a worse network, for testing

type Simulate

type Simulate = {latency?: number, jitter?: number, loss?: number}

The simulated network of options.simulate.

latency?: number
ms added to every packet, each way
jitter?: number
up to this many ms more, at random
loss?: number
the probability that a packet is dropped, 0 to 1

type net.Peer

The round-trip time in ms, smoothed.

The part of the packets sent to it that were lost lately, 0 to 1.

Whether it is still connected.

type net.Server

net.Server.protocol: Protocol? (read-only)

net.Server:on(event: string, handler: function?)

Sets the handler of an event ("connect", "disconnect") or a message name, replacing the one before; null removes it.

net.Server:broadcast(name: string, data?: any, options?: BroadcastOptions)

Queues a message for every connected peer (encoded once).

net.Server:poll()

Handles what arrived (the handlers run), drops clients that timed out and sends what is queued. A game calls it once per frame.

net.Server:flush()

Sends what is queued now, without waiting for the next Server.poll.

net.Server:run(options?: RunOptions)

Polls rate times a second until Server.close, for a server without a frame loop of its own. Outside slang/async it runs the event loop and returns once the server is closed; inside, it returns at once.

net.Server:close()

Tells every peer and stops listening; the "disconnect" handler runs for each.
