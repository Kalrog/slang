slang/symbols

slang/symbols: what a file defines and uses, for the language server (hover, go to definition, references) and slang doc.

local index = symbols.analyse(block, source, origin)
local found = symbols.at(index, pos)   // the def or ref at pos

block is the file's parsed (expanded) AST; codegen resolves its names as it would compile them (see codegen.generate's record option), so scoping is exactly the compiler's, extensions included. Names an extension made up have no place in the source and are left out. The result is an Index; its positions are byte offsets into source.

Doc comments are read here too: a definition's doc is the comment block right above its statement (no blank line between). Its typed signature, its [name]: text lines and the types a file declares follow the notation described under "typed docs" below (doc_info, types).

doc comments

symbols.doc_above(source: string, pos: int) -> string?

The comment block just above the line of pos (no blank line or section divider between), its lines without // and joined by newlines; null when there is none or it is the comment that starts the file (the module's doc).

symbols.doc_blocks(text?: string) -> {DocBlock}

A doc split into paragraphs and code samples. Lines indented by two or more spaces are code, kept as they are less their common indentation; a blank line ends a paragraph, not a sample.

typed docs

symbols.parse_type(text: string) -> Type?

The type text is in the notation (all of it), or null.

symbols.type_text(t?: Type) -> string

The type written out again in the notation; "any" for null.

symbols.doc_info(doc?: string, name?: string) -> DocInfo

Reads a definition's doc: the typed signature at its start (when the first line has name and a parameter list, maybe qualified: http.serve( for serve), its [name]: text lines, and the rest.

name
the definition's name; null reads no signature (a type's doc)

symbols.types(source: string) -> {[string]: TypeDecl}

The // type Name = T and // type Name lines of a file, by name (a declaration may go on over lines until its braces and parentheses close). A bare one's methods are the table defined right below its comment block; analyse finds that table, this does not.

analysis

symbols.analyse(block: table, source: string, origin?: string) -> Index

The definitions and uses of a file. A block that does not compile (an unfinished edit) still gives the names up to where it fails.

block
the file's AST, parsed from source (expanded)
origin
the file's name, as codegen gets it

queries

symbols.at(index: Index, pos: int) -> Def | Ref | null

The definition or use whose name covers pos (its end included).

symbols.signature(def: Def) -> string

The definition as it is called, from its parameter names: "http.fetch(url, options)" for a field of http, "x" for no function.

type Index

type Index = {defs: {Def}, refs: {Ref}, globals: {[string]: Def}, by_start: {[int]: Def | Ref}, exports: {[string]: Def}, returned?: Def, module_doc?: string, sections: {Section}, types: {[string]: TypeDecl}, origin?: string}

What analyse finds in a file.

defs: {Def}
the definitions, in source order
refs: {Ref}
the uses, in source order
globals: {[string]: Def}
the first definition of each global the file assigns
by_start: {[int]: Def | Ref}
the def or ref whose name starts at an offset
exports: {[string]: Def}
the fields of the table the file returns
returned?: Def
what the file returns, when that is a table, function or require
module_doc?: string
the comment block that starts the file
sections: {Section}
the section dividers (// ---- title), in order
types: {[string]: TypeDecl}
the types the doc comments declare, by name
origin?: string

type Def

type Def = {name: string, kind: string, start?: int, stop?: int, statement?: int, value?: table, doc?: string, info: DocInfo, params?: {string}, owner?: Def, module?: string, fields: {[string]: Def}, scope?: {start: int, stop: int}, type?: Type}

A definition: a local, a parameter, a global's first assignment or a field (o.name = v, a table literal's name: v).

name: string
kind: string
"local", "parameter", "global" or "field"
start?: int
where the name starts (stop: past its end); null when not in source
stop?: int
statement?: int
where the statement that defines it starts (its doc is above)
value?: table
the AST node it is given
doc?: string
the comment block above its statement
info: DocInfo
its doc read by doc_info
params?: {string}
the parameter names, when the value is a function
owner?: Def
a field's table: its definition, or {global, name, fields}
module?: string
the name, when the value is require("name")
fields: {[string]: Def}
the fields set on it by name: the first definition of each
scope?: {start: int, stop: int}
a local's block, function or loop; null at the top level
type?: Type
a parameter's, from its function's typed signature; a local's or field's, from a first doc line name: Type

type Ref

type Ref = {name: string, start: int, stop: int, def?: Def, write: bool, owner?: Def | {receiver: table, fields: table}, invoke?: bool, value?: table}

A use of a name. (a.b.c, f().x) {receiver}, the expression's AST node, which only tools that follow values can resolve

name: string
start: int
stop: int
def?: Def
what it resolved to; null for a global or field the file lacks
write: bool
it is assigned
owner?: Def | {receiver: table, fields: table}
a field's table, as for Def; for a field read of an expression
invoke?: bool
the field is called as a method (o:name())
value?: table
the AST node a write assigns
