slang/ffi

slang/ffi: calling C libraries without writing C. C declarations are read from text (a header, or a few lines) and a library is loaded with them; its functions are then called like slang functions:

local ffi = require("slang/ffi")
local C = ffi.cdef("typedef struct { int quot; int rem; } div_t; div_t div(int, int); int abs(int);")
local libc = ffi.load(null, C)       // null: the program itself (libc)
libc.abs(-3)                         // 3
libc.div(17, 5)                      // {quot: 3, rem: 2}

A header is read as C reads it: the preprocessor runs (#define, #if, function-like macros; #include is skipped), then the declarations are parsed: typedefs, structs, enums, function prototypes (function bodies, as in inline functions, are skipped). Enum values and #define constants become C.constants.

How values cross (slang/ctypes does the conversions): numbers and bools for the arithmetic types; a string for const char *; a table for a struct (fields by name or by position), returned as a table with the fields by name; for a pointer null, a pointer, a string (its bytes), or a table: a list of elements, or one struct, which is copied back after the call when the pointer is not to const (an out parameter). Pointers index like C (p[i], p.field) and assign; ffi.new allocates memory the collector frees.

A wrong declaration crashes the program as it would in C: the FFI calls what it is told is there. Callbacks (C calling slang), unions, bit fields and long double are not supported yet. Builds made without libffi (-Dffi=false) have types and memory but no calls: load raises there, and available says which it is.

declarations

ffi.cdef(text: string, options?: CdefOptions) -> Decls

Reads C declarations: the preprocessor runs, then typedefs, structs, enums and function prototypes are parsed. Raises "ffi.cdef: ..." naming the line for what it cannot parse.

local C = ffi.cdef(os.read_file("mylib.h"), {defines: {MYLIB_API: ""}})

types by name

ffi.type(name: string, decls?: Decls) -> Type

The type a C type name stands for: "int", "uint8_t", "Vector2", "struct foo", "Vector2 *", "float[4]".

decls
the declarations that define the struct and typedef names

ffi.new(t: string | Type, n?: int, decls?: Decls) -> Pointer

A pointer to n (1 by default) zeroed values of t, memory the collector frees once nothing points into it.

ffi.sizeof(t: string | Type, decls?: Decls) -> int

The size of a C type in bytes.

ffi.cast(p: Pointer | int, t?: string | Type, decls?: Decls) -> Pointer

The same address as a pointer to t (null: void *). An int is taken as an address.

ffi.string(p: Pointer?, n?: int) -> string?

The zero-terminated C string at p, or the n bytes there; null for a null pointer.

ffi.offset(p: Pointer, n: int) -> Pointer

The pointer n elements further (bytes for a void pointer); n may be negative.

ffi.address(p: Pointer?) -> int

The address as an int (0 for null).

ffi.value(p: Pointer) -> any

What p points to, copied: a number, or a table for a struct. Raises for a void pointer.

libraries

ffi.load(name: string?, decls: Decls, options?: LoadOptions) -> Library

Loads a C library with the declarations of its functions. A library name ("raylib") is libraylib.dylib or .so in options.paths, slang's native search paths, /opt/homebrew/lib, /usr/local/lib, /usr/lib, then wherever the system finds it. Raises "ffi.load: ..." with what each attempt said when it cannot load it.

name
a path (with a / or a .), a library name, or null for the program

ffi.bind(lib: Library, f: FunctionDecl, name?: string) -> function

The slang function calling the C function f declares (from decls.functions), bound to lib; lib.Name does the same for a declared name. Raises when the library lacks the symbol or a parameter's type cannot cross.

name
what errors call it (its C name by default)

ffi.available() -> bool

Whether this slang can call C (it was built with libffi).

type Type

A C type: made by type from a name ("int", "Vector2 *", "float[4]"), and given to new, sizeof, cast and slang/buffer. Types live as long as the program.

type Pointer

An address and the type it points to (none for void *). p[i] reads or writes the i-th element, p.field a field of a struct; an element or field that is a struct is a pointer again, so p.pos.x = 3 writes in place. Pointers are == when their addresses are.

type Decls

type Decls = {types: {[string]: table}, functions: {[string]: FunctionDecl}, constants: {[string]: any}, structs: table, order: {string}}

What cdef read: the declarations a library is loaded with.

types: {[string]: table}
the typedefs and structs by name ("Vector2", "struct foo")
functions: {[string]: FunctionDecl}
the function prototypes by C name
constants: {[string]: any}
enum values and #define constants (numbers, strings, structs)
structs: table
order: {string}
the function names in the order they were declared

type FunctionDecl

type FunctionDecl = {name: string, ret: table, params: {table}, variadic: bool, doc: string, line: int}

A function prototype cdef read.

name: string
ret: table
the parsed return type
params: {table}
the parsed parameters, each {name, type}
variadic: bool
doc: string
its comment, trailing or the lines right above ("" for none)
line: int
where it starts in the text

type CdefOptions

type CdefOptions = {defines?: {[string]: any}, field_name?: func(name: string): string, defaults?: {[string]: {[string]: any}}, into?: Decls}

What cdef accepts besides the text.

defines?: {[string]: any}
macros for the preprocessor, like -D
field_name?: func(name: string): string
renames struct fields for slang (C's names by default)
defaults?: {[string]: {[string]: any}}
values for fields a table leaves out: {Color: {a: 255}}
into?: Decls
earlier declarations to add to, so headers can build on each other

type Library

A loaded C library: its functions by their C names (lib.abs(-3)), bound on first use; a name the declarations do not have is null.

type LoadOptions

type LoadOptions = {paths?: {string}}

Where load looks for a library given by name.

paths?: {string}
directories searched first
