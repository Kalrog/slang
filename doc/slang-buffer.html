slang/buffer

slang/buffer: typed memory. A buffer holds n values of one C type, a scalar or a struct, in memory slang indexes about as fast as a list and C reads without a copy (a buffer passed to slang/ffi is its memory).

local buffer = require("slang/buffer")
local samples = buffer.new("float", 44100)
for(local i = 0; i < len(samples); i = i + 1){
  samples[i] = math.sin(i * 0.05)
}
local points = buffer.new("Vector2", 100, rl.decls)
points[3].x = 10                       // a struct element is a view

Indexes count from 0, like lists, and are checked: an index out of range raises. b[i] of a scalar is a number; of a struct a pointer to the element (ffi.Pointer), so b[i].x = 3 writes in place; b[i] = v converts v as slang/ffi does (a table for a struct). len(b) is the number of elements, == compares type and contents, and values, keys and entries iterate a buffer like a list. The methods are those of Buffer.

Types are C names: scalars ("float", "double", "int", "uint8_t", "int32", ...) or, with declarations from ffi.cdef, structs ("Vector2"); an ffi.Type value works too. Memory a buffer allocates is zeroed and freed by the collector once nothing refers to it (slices, casts and element pointers keep it alive).

buffer.new(t: string | ffi.Type, n: int, decls?: ffi.Decls) -> Buffer

A buffer of n zeroed elements of type t.

decls
the declarations that define t, when it is a struct name

buffer.from(src: {any} | string, t: string | ffi.Type, decls?: ffi.Decls) -> Buffer

A buffer with the elements of a list (numbers, or tables for structs), or with the bytes of a string, which must be a whole number of elements.

local b = buffer.from({1, 2, 3}, "int32")

buffer.from_string(s: string) -> Buffer

A uint8 buffer with the bytes of s, copied.

buffer.wrap(p: ffi.Pointer, n: int, t?: string | ffi.Type, decls?: ffi.Decls) -> Buffer

A buffer over n elements of memory C owns, without a copy: of the pointer's type, or of t (needed for a void pointer). It is valid only as long as C keeps the memory.

local vertices = buffer.wrap(mesh.vertices, mesh.vertex_count * 3)

buffer.is(v) -> bool

Whether v is a buffer.

type Buffer

type Buffer = {size: func(): int, type: func(): ffi.Type, slice: func(from?: int, to?: int): Buffer, copy: func(): Buffer, fill: func(v: any): Buffer, set: func(src: {any} | Buffer, at?: int): Buffer, cast: func(t: ffi.Type): Buffer, to_list: func(): {any}, to_string: func(): string, same: func(other: any): bool, pointer: func(): ffi.Pointer}

A buffer: n elements of one C type in a row. Methods are called with : (b:size()).

slice and set raise when the indexes are out of range; set copies correctly between overlapping slices of one buffer. fill and set return the buffer.

size: func(): int
the size in bytes
type: func(): ffi.Type
the element type
slice: func(from?: int, to?: int): Buffer
the elements from .. to - 1 (all by default), sharing the memory
copy: func(): Buffer
a new buffer with the same elements, in memory of its own
fill: func(v: any): Buffer
sets every element to v; returns the buffer
set: func(src: {any} | Buffer, at?: int): Buffer
writes a list's elements, or a buffer's of the same type, from at (0)
cast: func(t: ffi.Type): Buffer
a view of the same bytes as another type, as many as fit whole
to_list: func(): {any}
the elements as a list, structs copied into tables
to_string: func(): string
the bytes as a string
same: func(other: any): bool
whether other is a buffer of the same address, length and type
pointer: func(): ffi.Pointer
a pointer to the first element, keeping the memory alive
