slang/format: the formatter (slang fmt).

Formatting works on the lossless tree of a file (see slang/peg), not on its AST: extension syntax is expanded while parsing, so only the tree still shows what was written. The layout comes from marks in the format layer, set on the parsers of the grammar (format.gaps, format.indent, ...): they say what goes between two tokens, what is a group that is laid out on one line or broken, what is indented. A document printer in the style of Wadler's "prettier printer" then fits the result into 80 columns.

Syntax that extensions add is formatted when the extension marks its parsers like the core does (format.gaps, format.indent, ...). Unmarked, it keeps its own line structure (verbatim mode): its gaps are what the source has, re-indented to where the syntax now sits. Core syntax inside it (an expression, a block) is formatted either way.

format.source checks its own result before returning it: the output has the same tokens as the input (but for dropped ; and trailing commas), the same AST, and the same comments in the same order.

format.uses_marks(parser)

whether parser (or a parser inside it) carries layout marks; rule references and parts already marked formatted or verbatim are not looked into (they have a layout of their own)

format.extension(parser)

extension(parser) -> the parser an extension registered, formatted when it uses marks, else verbatim (what the grammar applies to the syntax an extension adds)
