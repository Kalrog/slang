slang/json

slang/json: encode and decode JSON.

local json = require("slang/json")
local v = json.decode("{\"name\": \"slang\", \"tags\": [1, 2]}")
print(v.name, " ", v.tags[1], "\n")                // slang 2
print(json.encode({ok: true, items: {1, 2}}), "\n") // {"ok":true,"items":[1,2]}

How values map: JSON objects are tables with string keys, arrays are lists, numbers are ints when they have no fraction or exponent, else doubles. JSON null is slang null, so a member that is null in the text is simply absent from its table. When encoding, a table whose keys are 0..n-1 (or one marked with array) is an array, any other table an object, which must have only string keys. An empty table encodes as {} unless marked with array. Use null for a member that must be there as null: {result: json.null} encodes as {"result":null}. Functions, NaN and the infinities cannot be encoded and raise an error.

decoding

json.decode(text: string, origin?: string) -> any

The value of the JSON text. Raises "invalid JSON in <origin> at line:col: ..." on malformed input. Decoded arrays carry the array mark, so they encode as arrays again even when empty.

origin
names the text in error messages ("string" by default)

encoding

json.null

A value that encodes as null, for a member that must be present (a member set to slang null is left out). type() of it is "json.null".

json.array(t: table) -> table

Marks t (setting its metatable) so that it encodes as a JSON array even when empty, and returns it.

json.encode({items: json.array({})})   // {"items":[]}

json.encode(value, options?: EncodeOptions) -> string

The JSON text of value; see the module doc for how values map. Object members come in the table's key order.

json.encode({a: 1}, {indent: "  "})   // "{\n  \"a\": 1\n}"

type EncodeOptions

type EncodeOptions = {indent?: string}

How encode writes.

indent?: string
pretty-prints, with this string per level of nesting
