slang/ctypes

slang/ctypes: C types and C memory, in every build: the native part of slang/ffi and slang/buffer, which most code uses instead. Types are ffi.type values and live as long as the program. Memory is a pointer (ffi.pointer: an address, indexed like C) or a buffer (an address with a length, checked; see slang/buffer).

m.primitive(name)

primitive(name) -> a type: void, bool, char (an int8 whose arrays are strings), int8..int64, uint8..uint64, float, double, pointer (void *) or string (const char *)

m.pointer(target)

pointer(target) -> the type of a pointer to target (null: void *)

m.array(elem, n)

array(elem, n) -> the type of n elems in a row (a struct field)

m.struct(name)

struct(name) -> a struct type, opaque until define gives its fields

m.define(struct_type, fields)

define(struct_type, {{name, type, [default]}, ...}): the fields, laid out by C's rules; default is used when a table leaves the field out

m.sizeof(type)

sizeof(type) -> its size in bytes

m.offsetof(type, field)

offsetof(type, field) -> the offset of a struct field

m.type_name(type)

type_name(type) -> its name in messages ("Vector2 *")

m.new(type, n)

new(type, [n]) -> a pointer to n zeroed values the collector frees

m.cast(pointer, type)

cast(pointer, type) -> the address as a pointer to type (an int is an address)

m.offset(pointer, n)

offset(pointer, n) -> the pointer n elements further

m.address(pointer)

address(pointer) -> the address as an int

m.string(pointer, len)

string(pointer, [len]) -> the C string at pointer, or len bytes

m.value(pointer)

value(pointer) -> the value pointed to, copied (a struct as a table)

m.buffer(type, n)

buffer(type, n) -> a buffer of n zeroed elements

m.buffer_from(type, src)

buffer_from(type, list or string) -> a buffer of the list's elements, or of the string's bytes

m.wrap(pointer, n, type)

wrap(pointer, n, [type]) -> a buffer over n elements of C's memory

m.is_buffer(v)

is_buffer(v) -> whether v is a buffer
