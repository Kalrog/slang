slang/http

slang/http: an HTTP/1.1 server and client on slang/async, parsing with llhttp (the llhttp native extension) and compressing with zlib.

local http = require("slang/http")
local async = require("slang/async")
async.main(func(){
  local s = http.serve("127.0.0.1", 8080, func(req){
    return {status: 200, body: concat("you asked for ", req.path)}
  })
  print("listening on ", s.port, "\n")
  async.await(s.done)
})

Requests. A handler receives {method, path, query, url, version, headers, body} (header names lowercased; a repeated header joined with ", ", cookie with "; "; query the raw text after ?). The body is read whole first, up to max_body bytes (413 beyond). When stream_body(req) says so (it sees the request before its body), req.body is null and req.stream a Stream of the body's chunks instead, for uploads; the handler should read it to the end (what it leaves is discarded). Chunked request bodies are de-chunked either way; Expect: 100-continue is answered.

Responses. A handler returns a string (200, text/plain), a response table {status, headers, body}, or a Future of either (an async function works as a handler). body is a string or a Stream of strings; a Stream is sent chunked as it comes (unless the headers give a Content-Length). A header whose value is a list is sent once per element (several Set-Cookie); Date is added. Text-like bodies (text/*, JSON, JavaScript, XML, SVG) of 1 KiB or more, and text-like Streams, are gzipped when the client accepts gzip, unless the response sets Content-Encoding or compress: false (or the server option compress is false). HEAD requests get the headers alone.

serve(host, port, handler, options) -> {server, port, done, close()}; options:

max_head (64 KiB; 431 beyond), max_body (16 MiB; 413 beyond),
stream_body(req) -> bool, compress (true),
idle_timeout (5000 ms between requests on a kept-alive connection),
request_timeout (30000 ms to receive a request; 408 after),
on_error(req, err) (a handler raised; the client gets a 500),
on_upgrade(req, conn, rest) (a request asked for another protocol,
  like WebSocket; it gets the connection and the bytes read past the
  head, and the server forgets the connection),
tls (serve HTTPS: {cert, key} as PEM text, or {cert_file, key_file},
  or a context from slang/tls; req.secure is true then).

close() stops accepting; idle connections close at once, busy ones after their response; done completes when the listener is closed.

Client:

http.connect(host, port, options) -> Future of a client;
  client:request(method, path, body, headers) -> Future of {status,
  reason, headers, body}, one at a time on the connection;
  client:close()
http.get(host, port, path) -> Future of a response
http.fetch(url, {method, headers, body, tls}) -> Future of a response
  to an http:// or https:// URL

options.tls makes a client talk HTTPS: true, or the options of slang/tls's connect (ca to trust a server's own certificate, verify: false, ...); fetch uses it for https:// URLs. The client says User-Agent: slang unless told otherwise, asks for gzip and inflates it (res.compressed says it was); chunked and connection-delimited responses are read to their end.

Multipart (form uploads):

http.multipart_boundary(content_type) -> the boundary, or null
http.multipart_parser(boundary) -> p; p:push(chunk) -> events
  {type: "part", name, filename, content_type, headers},
  {type: "data", data}, {type: "end_part"}, {type: "end"}; p:finish()
  raises when the body ended early
http.multipart(req) -> list of {name, filename, content_type, headers,
  data} of a buffered body

Cookies:

http.cookies(req) -> {name: value} from the Cookie header
http.set_cookie(res, name, value, options) adds a Set-Cookie header
http.clear_cookie(res, name, options) tells the browser to drop it
http.cookie(name, value, options) -> the Set-Cookie header value

options: path ("/"), domain, max_age (seconds), expires (seconds since the epoch), http_only (true), secure, same_site ("Lax"; "Strict" or "None"). Values must be cookie-safe (encode others first, for example with slang/encoding's base64url_encode).
