slang/ffi_core

slang/ffi_core: calls to C through libffi, the native part of slang/ffi (which most code uses instead). Types and memory are slang/ctypes'. Builds made with -Dffi=false do not have it.

  • open
  • symbol
  • func

m.open(path)

open(path) -> a library (dlopen), or {null, message}; null is the program itself

m.symbol(library, name)

symbol(library, name) -> a pointer to the symbol, or null

m.func(symbol, ret, args, name, writeback, variadic)

func(symbol, ret, args, name, [writeback], [variadic]) -> a function calling the C function at symbol: args is the list of parameter types, writeback marks the pointer parameters whose tables get the memory back after the call, variadic allows extra arguments (C's promotions)
