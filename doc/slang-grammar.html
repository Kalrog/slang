slang/grammar

slang/grammar: the slang grammar, built with slang/peg on top of a rule registry that lets programs extend and modify the parser at compile time.

A grammar is a registry of named rules plus the registries of statements, extension statements and the expression walker (primaries, levels and operators, see peg.walker). Rules are referenced by name (g:rule(name)) and resolved late: the first parse after a change seals the grammar (builds the expression walker, the dispatch tables and the rule targets) once. Grammars derive from each other; the rule references are shared by a whole lineage and always point at the rules of the grammar that was activated last.

rule(name) -> a parser referring to the rule, resolved at parse time

grammar:define(name, parser, options)

define(name, parser, {protected, probe}): registers a rule. A rule may also be built at seal time: define(name, null, {build: func(g) -> parser}).

grammar:modify(name, f)

modify(name, func(old) -> new): replaces the rule by f(old); replacing is just not using old. Rules built at seal time are wrapped after building.

rules() -> {{name, owner, protected, history}}: every rule with its provenance

grammar:keyword(s)

keyword(word) -> token parser; the word is reserved (not an identifier)

grammar:token(source, name, category)

token(source, name, category) -> parser: a token trimmed by trivia. source is a string (the token's text; word-like tokens may not be followed by an identifier character) or a parser (name says what the error message expects). category is what a highlighter shows; it defaults to "keyword" for words, "punctuation" for other strings and name for parsers.

tag(parser, category) -> parser: what parser produced, recorded again under category for highlighting (see peg.tag)

unit_id() -> a number identifying the parse of the current unit (a new one for every unit, including nested compiles), for per-unit extension state

uniq_id() -> an identifier node with a name no program can write

grammar:seal()

seal(): builds the rule targets, the expression walker and the dispatch tables of this grammar. Rules built at seal time (expr, statement, extension_statement) are built in that order, each installed before the next is analysed, so first sets never come from a stale definition.

grammar:activate()

activate(): makes this grammar the one the rule references parse with, sealing it first when it changed

grammar:statement(name, parser)

statement(name, parser): a statement; the parser yields a statement node or {token, ast}

grammar:extension_statement(name, parser, apply)

extension_statement(name, parser, apply): a statement that is only recognised at the top level; after it parsed, apply(result, g) runs between statements with grammar changes allowed (g is the grammar of the unit being parsed) and returns the statement to emit (or null)

grammar:walker()

walker() -> a fresh expression walker skipping slang trivia, for extensions that define their own expression language (see peg.walker)

grammar:run_extension(parsed, origin)

runs a parsed extension statement; returns a statement node to emit or null

grammar:parse_source(source, origin, options)

parse_source(source, origin, {scoped, tree, recover}) -> Block node (raises on failure; the details of a parse failure are in g.state.last_failure). Extension statements of a scoped unit (the default) only affect that unit. With tree, the lossless tree of the unit is left in g.state.last_tree (see slang/peg): a node of kind "unit" whose kids are the top-level statements; after a failure, the statements parsed before it. recover (with tree, for highlighting) goes past statements that fail to parse: they are error regions in the tree (with highlight functions, see peg.highlights) and their failures are in g.state.failures.

grammar:parse_repl(source)

parse_repl(source) -> node: a chunk, or an expression wrapped in a return. The REPL is one unit spread over many lines: its extension statements are not scoped.
