slang/codegen

slang/codegen: compiles AST nodes into function prototypes, tables that slang/vm's load_proto turns into functions.

local proto = codegen.generate(ast_node, "main.slang")
local f = vm.load_proto(proto)

The AST is core slang (see slang/ast): extension syntax is expanded and unquotes are resolved by the parser before code is generated. Names are resolved here, which is also how slang/symbols learns a file's scoping (the record option of generate).

codegen.generate(node: table, origin?: string, options?: {record?: table}) -> Prototype

Compiles an AST node (a chunk, usually) into the prototype of a function that runs it; it reaches globals through the upvalue _ENV. Raises on what cannot compile (break outside a loop, a variable declared twice, an unresolved unquote, ...). define, use and field methods (see record_local above and slang/symbols)

origin
the name in locations and error messages; "string" by default
options
record, a recorder told of names as they are resolved, with

type Prototype

type Prototype = {code: {int}, locations: {{any}}, constants: {any}, upvalues: {{any}}, children: {Prototype}, max_stack: int, nargs: int, is_vararg: bool, name?: string, locals: {{any}}}

A compiled function, before the VM loads it.

code: {int}
the instructions, encoded as the VM expects them
locations: {{any}}
{instruction index, origin, line, column} where they change
constants: {any}
upvalues: {{any}}
{name, index, from a local of the enclosing function: bool}
children: {Prototype}
the prototypes of the functions defined in it
max_stack: int
the registers it needs
nargs: int
its fixed parameters
is_vararg: bool
name?: string
the name its definition gives it, for stack traces
locals: {{any}}
{name, register, first pc, end pc} of each local, for debuggers
