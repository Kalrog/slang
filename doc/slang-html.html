slang/html

slang/html: HTML nodes that render to a string; the runtime behind the JSX-like templates of extensions/html, and usable on its own.

html.element(tag, attrs, children) -> node    <tag attrs>children</tag>
html.fragment(children) -> node               children without a tag
html.raw(s) -> node                           s inserted as it is
html.value(v) -> what {v} in a template inserts: a string escaped, a
                 number printed, a node or a list kept (lists element
                 by element), null and booleans nothing ("": a null
                 would end the list of children it sits in)
html.escape(s) -> s with & < > " ' escaped
html.render(v) -> the string of v; string(node) renders too
html.write(out, v)   appends the pieces of v to the list out
html.doctype         the <!DOCTYPE html> node

The children of element and fragment, and any list with html.list as its meta, are trusted: their strings are markup (the extension escapes literal text when it compiles it, and wraps every {expr} in value), and value passes such a list through, so children handed to a component are not escaped twice. Attribute values are escaped when rendered, null and false omit the attribute, true writes it bare. Void elements (br, img, ...) have no end tag.
