slang/jwt

slang/jwt: JSON Web Tokens (RFC 7519) over slang/crypto.

jwt.sign(claims, key, options) -> token
jwt.verify(token, key, options) -> the claims, or raises "jwt: ..."
jwt.decode(token) -> {header, claims} without checking anything

key is a secret string for HS256/384/512, or a crypto key: RSA for RS256/384/512 and PS256/384/512, EC for ES256/384/512, Ed25519 for EdDSA. The algorithm defaults to the one that fits the key (HS256, RS256, ES256/384/512 by curve, EdDSA).

sign options: alg, expires_in (seconds from now: sets exp), not_before (seconds from now: nbf), issuer, subject, audience, header (extra header fields such as kid); iat is always set. verify options: alg or algs (the algorithms accepted; by default only the one that fits the key, so a token cannot choose a weaker one), leeway (seconds of clock skew allowed, default 0), now (seconds since the epoch, for tests), issuer and audience (required to match when given).
