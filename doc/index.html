slang's library

crypto
crypto: the native binding of the parts of OpenSSL 3 (libcrypto) that web applications need.
globals
globals: the functions every slang program has, built into the VM.
llhttp
llhttp: the native binding of llhttp, the HTTP/1 parser of Node.js.
slang/ast
slang/ast: helpers for AST nodes.
slang/async
slang/async: Futures, Streams and await on coroutines, driven by the uv event loop (the native uv module).
slang/codegen
slang/codegen: compiles AST nodes into function prototypes.
slang/compiler
slang/compiler: the compiler driver.
slang/crypto
slang/crypto: the crypto native extension (OpenSSL) plus what web code builds from it: password hashes, random tokens, signed and sealed values.
slang/doc
slang/doc: API documentation from the comments the code already has, as HTML: slang doc [-o dir] [file|dir...].
slang/encoding
slang/encoding: the byte encodings web code needs, built into the VM.
slang/format
slang/format: the formatter (slang fmt).
slang/grammar
slang/grammar: the slang grammar, built with slang/peg on top of a rule registry that lets programs extend and modify the parser at compile time.
slang/html
slang/html: HTML nodes that render to a string; the runtime behind the JSX-like templates of extensions/html, and usable on its own.
slang/http
slang/http: an HTTP/1.1 server and client on slang/async, parsing with llhttp (the llhttp native extension) and compressing with zlib.
slang/json
slang/json: encode and decode JSON.
slang/jwt
slang/jwt: JSON Web Tokens (RFC 7519) over slang/crypto.
slang/math
slang/math: numeric functions, built into the VM.
slang/optimizer
slang/optimizer: constant folding on the AST (applied to parsed chunks).
slang/os
slang/os: files, the process and its environment, built into the VM.
slang/peg
slang/peg: parser combinators in the style of petitparser.
slang/sqlite
slang/sqlite: SQLite with an API that reads well, on the native sqlite extension.
slang/std
slang/std: global helpers written in slang.
slang/string
slang/string: string functions, built into the VM.
slang/symbols
slang/symbols: what a file defines and uses, for the language server (hover, go to definition, references) and slang doc.
slang/table
slang/table: table helpers.
slang/test
slang/test: a small test framework.
slang/thread
slang/thread: cooperative coroutines, built into the VM.
slang/time
slang/time: wall-clock time as seconds since the Unix epoch, in UTC, built into the VM.
slang/tls
slang/tls: TLS on libuv TCP, with the tls native extension (OpenSSL).
slang/web
slang/web: the application layer on slang/http: routes, middleware, request helpers, responses, static files, sessions, CSRF protection, WebSocket routes and a test client.
slang/webview
slang/webview: desktop windows whose content is a web page and whose logic is slang (macOS, WKWebView), in the style of Wails.
slang/ws
slang/ws: WebSockets (RFC 6455) on slang/async.
sqlite
sqlite: the native binding of SQLite, as thin as it is useful.
tls
tls: the native binding of OpenSSL 3's TLS (libssl) as an engine on memory buffers.
uv
uv: the native binding of libuv in the callback style of luv.
zlib
zlib: the native binding of zlib (deflate and inflate in the gzip, zlib and raw formats), at once or as a stream.
