slang/pkg

slang/pkg: packages: slang get, slang update [name...], slang deps.

A project lists what it uses in its slang.project:

name: "app",
dependencies: {
  json5: {git: "https://github.com/someone/json5", version: "^1.2"},
  util: {path: "../util"},
},

A package is a git repository whose slang.project gives its name (the name it is required by, the same in every project that uses it) and whose tags vMAJOR.MINOR.PATCH are its versions. version: "1.2" (or "^1.2") asks for 1.2.0 or later within major 1 (within 0.2 for a 0.x version); a path dependency is a directory, for working on two packages at once. require("json5/parse") loads parse.slang of the package (require("json5") its init.slang), compiled under the package's own slang.project: its extensions never reach the project that uses it.

Versions are chosen as Go does (minimal version selection): every package gets the highest of the minimums asked for it, by the project, by other packages, or by slang.lock, which pins what was chosen (the version, its commit and a hash of its files). So a build is the same until someone asks for more: slang update moves the named packages (or all) to their newest version within the same major. Two majors of one package, or two packages under one name, are errors: one program never mixes them.

Packages are fetched with git into the package cache ($SLANG_PKG_DIR, else ~/.slang/pkg; a git mirror per repository under .mirrors), one directory per version; with the cache complete nothing needs the network. Nothing in a package runs when it is fetched: there are no install scripts. Compiling a package runs its grammar extensions, as compiling any slang does; the hashes in slang.lock pin exactly what that is.

versions

pkg.parse_version(s: string) -> Version?

Reads "v1.2.3", "1.2" or "^1.2" (missing parts are 0); null for anything else, pre-releases included.

pkg.compare(a: Version, b: Version) -> int

-1, 0 or 1 as a is lower than b, the same or higher.

pkg.compatible(a: Version, b: Version) -> bool

Whether b can stand in for a: the same major (and minor below 1.0). It does not compare them: see compare.

hashes

pkg.files_under(dir: string, rel: string, out: {table}) -> {table}

out with {rel, path} appended for every file under dir, in name order, directories walked; rel is the file's path relative to dir after the prefix rel ("" for none).

pkg.tree_hash(dir: string) -> string

"sha256:..." of the files under dir: their relative paths and contents, in order. What slang.lock records to pin a package's files.

selection

pkg.resolve(dir: string, manifest: table, lock: table, update?: bool | {[string]: bool}) -> {[string]: Chosen}

The build list of a project: every package it needs, directly or not, by name, with versions chosen by minimal version selection. Fetches the repositories it needs into their mirrors, but installs nothing. Raises on a conflict (two majors, two packages under one name) or a version no tag satisfies.

dir
the project's directory
manifest
its slang.project
lock
its slang.lock ({} without one)
update
null keeps slang.lock's versions; true updates all, a set some

commands

pkg.get(dir: string, update?: bool | {[string]: bool}) -> {[string]: Chosen}

slang get (and slang update with update): resolves the build list of the project in dir, installs what is missing into the package cache, checks the files against slang.lock's hashes and writes slang.lock.

update
as for resolve; the named repositories are fetched again

pkg.main(arguments: {string}) -> int

The commands: {"get"}, {"update", names...} or {"deps"}, for the project in the working directory or the nearest one above it.

returns
the exit code
