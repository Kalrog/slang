slang/class

slang/class: classes of objects with methods and properties, for libraries whose objects stand for something else (a C struct, a physics body, a database handle). A property reads as a field and is written as one: body.position calls its getter, body.position = p its setter, both through the object's metatable.

local class = require("slang/class")
local Counter = class.new({
  name: "demo.Counter",
  methods: {
    add: func(self, n){ self.state.n = self.state.n + n },
  },
  properties: {
    value: {get: func(self){ return self.state.n }},
    limit: {
      get: func(self){ return self.state.limit },
      set: func(self, v){ self.state.limit = v },
    },
  },
})
local c = class.make(Counter, {state: {n: 0, limit: 10}})
c:add(2)
c.value          // 2
c.limit = 20     // the setter
c.value = 5      // raises: demo.Counter.value is read-only
c.note = "mine"  // not a property: an ordinary field of c

A key the class does not know can be looked up lazily by options.resolve(key), which returns {method: f}, {get?: f, set?: f}, {gone: text} (a key that used to exist; reading or writing it raises with the text) or null; the answer is kept per class. Like any metatable, the class sees only keys the object does not hold itself: keep an object's own data under keys that are not property names.

class.new(options: {name: string, methods?: table, properties?: table, resolve?: function}) -> Class

A class: [Class.meta] is the metatable of its objects (its __type is name).

class.make(class: Class, fields?: table) -> table

An object of the class holding fields as its own (they are set raw: no setter runs).

class.of(v: any) -> Class?

The class of an object made by make (or given its meta), or null.
