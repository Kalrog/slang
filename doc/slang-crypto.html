slang/crypto

slang/crypto: the crypto native extension (OpenSSL) plus what web code builds from it: password hashes, random tokens, signed and sealed values.

local crypto = require("slang/crypto")
local stored = crypto.hash_password("hunter2")
crypto.verify_password("hunter2", stored)       // true
local cookie = crypto.sign_value(secret, "user=42")
crypto.unsign_value(secret, cookie)             // "user=42"
crypto.hex("sha256", "abc")                     // "ba7816bf..."

Everything the native module has is here too, under the same names: native.hash, native.hmac, native.equal, native.random_bytes, native.hasher, native.pbkdf2, native.scrypt, native.encrypt, native.decrypt, native.private_key, native.public_key, native.generate_key, native.version and the _async forms. Results are raw byte strings; slang/encoding makes hex or base64 of them.

Password hashes use scrypt with n = 2^15, r = 8, p = 1 (32 MiB, the OWASP recommendation) and a 16-byte salt; verify_password also accepts "$pbkdf2-sha256$i=...$salt$hash". seal uses AES-256-GCM with a random 12-byte iv and needs a 32-byte key.

crypto.hex(digest: string, data: string) -> string

The digest of data as lowercase hex.

crypto.token(n?: int) -> string

n random bytes (32 by default) as base64url text: a session id, a CSRF token, a key for a reset link.

passwords

crypto.hash_password(password: string) -> string

A salted scrypt hash to store, "$scrypt$ln=15,r=8,p=1$salt$hash". It takes tens of milliseconds on purpose; a server should prefer hash_password_async.

crypto.verify_password(password: string, stored: string) -> bool

Whether password matches a hash hash_password made (or a $pbkdf2-sha256$ one); false for a stored value it cannot read.

crypto.hash_password_async(password: string) -> async.Future

hash_password on libuv's thread pool: a Future of the hash, while the loop stays free.

crypto.verify_password_async(password: string, stored: string) -> async.Future

verify_password on libuv's thread pool: a Future of the bool.

signed and sealed values

crypto.sign_value(secret: string, value: string) -> string

"value.mac": value with an HMAC-SHA256 of it under secret, base64url. Anyone can read value; only who knows secret can make one that unsign_value accepts.

crypto.unsign_value(secret: string, signed: string) -> string?

The value sign_value signed, or null when signed was not made with secret or was changed.

crypto.seal(key: string, text: string, aad?: string) -> string

text encrypted and authenticated (AES-256-GCM, a random iv), as base64url of iv, ciphertext and tag.

key
32 bytes, such as native.random_bytes(32) kept secret
aad
data it is bound to without containing it (a user id); unseal needs it

crypto.unseal(key: string, sealed: string, aad?: string) -> string?

The text seal sealed, or null when sealed is malformed, was changed, or the key or the aad do not match.

type Key

type Key = native.Key

A key, as native.private_key, native.public_key and native.generate_key make it.

type Hasher

type Hasher = native.Hasher

An incremental hasher, from native.hasher.
