slang/html

slang/html: HTML nodes that render to a string. It is the runtime behind the JSX-like templates of extensions/html and works on its own.

local html = require("slang/html")
local page = html.element("ul", {class: "names"}, {
  html.element("li", null, {html.value("Tom & Jerry")}),
})
html.render(page)   // <ul class="names"><li>Tom &amp; Jerry</li></ul>

Trust: the children of element and fragment, and any list whose metatable is list, are trusted, so their strings are markup and are written as they are. Pass untrusted text through value (or escape) first; the extension does that for every {expr} in a template and escapes literal text when it compiles it. value passes trusted lists through, so children handed on to a component are not escaped twice.

Attributes: values are escaped when rendered; null and false leave the attribute out, true writes it bare (<input disabled>). Void elements (br, img, input, meta, ...) get no end tag.

html.escape(s: string) -> string

s with & < > " and ' replaced by their character references; s itself when there is nothing to replace.

html.list

The metatable that marks a list of children as trusted markup; type() of such a list is "HtmlList".

html.element(tag: string, attrs?: {[string]: any}, children?: {Content}) -> Node

The element <tag attrs>children</tag>. children becomes trusted: its metatable is set to list.

html.fragment(children?: {Content}) -> Node

The children without an enclosing tag. children becomes trusted, as for element.

html.raw(s: string) -> Node

A node that writes s as it is, unescaped.

html.doctype

The <!DOCTYPE html> node, to put before <html>.

html.is_node(v) -> bool

Whether v is a Node.

html.value(v) -> Content

What {v} in a template inserts: a string escaped, a number printed, a Node or trusted list kept, a plain list converted element by element into a trusted list, null and booleans "" (not null, which would end the list of children it sits in). Anything else is rendered with string() and escaped.

html.write(out: {string}, v: Content)

Appends the pieces of the markup of v to the list out; render joins them. Writing into one list avoids building strings for every node.

html.render(v: Content) -> string

The markup of v.

type Node

type Node = {tag?: string, attrs?: {[string]: any}, children?: {Content}, raw?: string}

A node; type() of it is "Html", and string(node) renders it.

tag?: string
the element's name; null for a fragment or raw markup
attrs?: {[string]: any}
the attributes by name
children?: {Content}
trusted content, marked with list
raw?: string
markup written as it is

type Content

type Content = string | int | float | Node | {Content}

What can be rendered: markup strings, numbers, nodes and lists of these. null and booleans write nothing.
