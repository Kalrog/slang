slang/http

slang/http: an HTTP/1.1 server and client on slang/async, parsing with llhttp (the llhttp native extension) and compressing with zlib.

local http = require("slang/http")
local async = require("slang/async")
async.main(func(){
  local s = http.serve("127.0.0.1", 8080, func(req){
    return {status: 200, body: concat("you asked for ", req.path)}
  })
  print("listening on ", s.port, "\n")
  async.await(s.done)
})

A handler receives a Request and returns a string (200, text/plain), a Response table or a Future of either (an async function works as a handler); serve takes ServeOptions. The body is read whole first, up to max_body bytes (413 beyond), unless stream_body asks for a Stream. Chunked request bodies are de-chunked either way; Expect: 100-continue is answered; HEAD requests get the headers alone. An error the handler raises becomes a 500.

A body that is a Stream is sent chunked as it comes (unless the headers give a Content-Length). Text-like bodies (text/*, JSON, JavaScript, XML, SVG) of 1 KiB or more, and text-like Streams, are gzipped when the client accepts gzip, unless the response sets Content-Encoding or compress: false (or the server option compress is false). Date is added.

The client side: connect gives an HttpClient for several requests on one connection; get and fetch make one request each. Responses are ClientResponses. Clients say User-Agent: slang unless told otherwise, ask for gzip and inflate it; chunked and connection-delimited responses are read to their end.

Also: multipart form bodies (multipart, multipart_parser) and cookies (cookies, set_cookie).

http.status_text

The reason phrase of each status code the server knows, like status_text[404] == "Not Found".

requests

http.parse_head(text: string) -> Request?

Parses the head of a request (up to the blank line): the Request with body "", or null when the text is malformed or incomplete.

responses

http.response(status: int, body?: string | async.Stream, headers?: {[string]: string | {string}}) -> Response

A Response table; body defaults to "" and headers to {}.

http.accepts_gzip(req: Request) -> bool

Whether the request's Accept-Encoding takes gzip (a q=0 turns it down).

http.normalize(res: string | Response) -> Response

What a handler returned as a full Response: status (200 by default), headers (a copy, with Content-Type text/plain unless given), body (a string or a Stream; other values are turned into strings) and compress. Raises for anything but a string or a table.

http.write_response(conn, req: Request, res: string | Response, options?: ServeOptions) -> async.Future

Sends res on a raw connection and closes it: for a connection from on_upgrade, to refuse the upgrade.

options
compress is the one that matters

connections

http.serve(host: string, port: int, handler: func(req: Request): string | Response | async.Future, options?: ServeOptions) -> Server

Serves HTTP (or HTTPS, with options.tls) on host:port until the Server is closed. Each connection is handled in its own async function; requests on one connection are answered in order. Raises when it cannot bind.

port
0 picks a free port; the Server's port says which

cookies

http.parse_cookies(header?: string) -> {[string]: string}

The cookies of a Cookie header value, by name; quotes around a value are dropped, and of a repeated name the first wins. Not a string: {}.

http.cookies(req: Request) -> {[string]: string}

The request's cookies by name (parsed once, kept in req.cookies).

http.cookie(name: string, value: string, options?: CookieOptions) -> string

The Set-Cookie header value for a cookie. Raises when the name is empty or the name or value holds bytes a cookie cannot (spaces, quotes, commas, semicolons, backslashes, control or non-ASCII bytes; = in the name): encode such values first, for example with slang/encoding's base64url_encode.

http.set_cookie(res: Response, name: string, value: string, options?: CookieOptions) -> Response

Adds a Set-Cookie header for the cookie to res (keeping those already there) and returns res. Raises as cookie does.

return http.set_cookie({body: "hi"}, "theme", "dark", {max_age: 86400})

http.clear_cookie(res: Response, name: string, options?: CookieOptions) -> Response

Adds a Set-Cookie header that tells the browser to drop the cookie and returns res. Give the path and domain it was set with.

client

http.connect(host: string, port: int, options?: {tls?: bool | table}) -> async.Future

A Future of an HttpClient connected to host:port.

options
tls: true, or slang/tls's connect options (ca, verify, ...), makes it HTTPS local c = async.await(http.connect("example.com", 80)) local res = async.await(c:request("GET", "/")) async.await(c:close())

http.get(host: string, port: int, path: string) -> async.Future

A GET request on a connection of its own: a Future of the ClientResponse. Plain HTTP only; see fetch for HTTPS.

http.fetch(url: string, options?: FetchOptions) -> async.Future

One request to an http:// or https:// URL, on a connection of its own: a Future of the ClientResponse. Redirects are not followed.

local res = async.await(http.fetch("https://example.com/"))
print(res.status, " ", len(res.body), "\n")

multipart

http.multipart_boundary(content_type?: string) -> string?

The boundary of a multipart/* Content-Type, or null for other types.

http.multipart_parser(boundary: string) -> MultipartParser

A parser for a multipart body with the boundary (see multipart_boundary). Raises when the boundary is empty.

local p = http.multipart_parser(http.multipart_boundary(req.headers["content-type"]))
for(true){
  local e = async.await(req.stream:next())
  if(e.done){ break }
  for(let local ev in values(p:push(e.value))){ ... }
}
p:finish()

http.multipart(req: Request) -> {Part}

The parts of a request's multipart body, read whole. Raises when the request is not multipart or the body is malformed. For a streamed body use multipart_parser.

type Request

type Request = {method: string, path: string, query?: string, url: string, version: string, headers: {[string]: string}, body?: string, stream?: async.Stream, content_length?: int, secure?: bool}

What a handler receives. Header names are lowercase; a repeated header is joined with ", " (cookie with "; ").

method: string
path: string
the URL up to ?, not decoded
query?: string
the raw text after ?; null when there is none
url: string
the request target as sent
version: string
the HTTP version, like "1.1"
headers: {[string]: string}
body?: string
the whole body ("" when none); null when [stream] is set
stream?: async.Stream
the body's chunks, when stream_body said so; read it to the end (the rest is discarded)
content_length?: int
the Content-Length the client gave
secure?: bool
true on an HTTPS server

type Response

type Response = {status?: int, headers?: {[string]: string | {string}}, body?: string | async.Stream, compress?: bool}

What a handler returns (or a string, the body of a 200 text/plain response). Fields left out default to status 200, Content-Type text/plain; charset=utf-8 and an empty body.

status?: int
headers?: {[string]: string | {string}}
a list value sends the header once per element (Set-Cookie)
body?: string | async.Stream
a Stream of strings is sent chunked as it comes
compress?: bool
false keeps the body from being gzipped

type ServeOptions

type ServeOptions = {max_head?: int, max_body?: int, stream_body?: func(req: Request): bool, compress?: bool, idle_timeout?: int, request_timeout?: int, on_error?: func(req: Request, err: any), on_upgrade?: func(req: Request, conn: any, rest: string), tls?: any, backlog?: int}

How a server behaves; every field is optional.

max_head?: int
the most bytes of a request head (64 KiB; 431 beyond)
max_body?: int
the most bytes of a body read whole (16 MiB; 413 beyond)
stream_body?: func(req: Request): bool
sees the request before its body; true hands the body over as req.stream
compress?: bool
false gzips nothing (true by default)
idle_timeout?: int
ms to wait for the next request on a kept-alive connection (5000)
request_timeout?: int
ms to receive a request (30000; 408 after)
on_error?: func(req: Request, err: any)
called when a handler raised; the client gets a 500
on_upgrade?: func(req: Request, conn: any, rest: string)
gets a request for another protocol (WebSocket), the connection and the bytes read past the head; the server lets go of the connection
tls?: any
serve HTTPS: {cert, key} as PEM text, {cert_file, key_file}, or a tls.context
backlog?: int
pending connections the listener queues (128)

type Server

type Server = {server: any, port: int, done: async.Future, close: func()}

A running server.

server: any
the listening uv.tcp handle
port: int
the port it listens on (useful after port 0)
done: async.Future
completes when the listener is closed
close: func()
stops accepting; idle connections close at once, busy ones after their response

type CookieOptions

type CookieOptions = {path?: string, domain?: string, max_age?: int, expires?: int, http_only?: bool, secure?: bool, same_site?: string}

How a cookie is set; every field is optional.

path?: string
"/" by default
domain?: string
max_age?: int
seconds until it expires
expires?: int
when it expires, in seconds since the epoch
http_only?: bool
true by default: scripts cannot read it

type HttpClient

A connection to an HTTP server, for requests one after another.

HttpClient:request(method: string, path: string, body?: string, headers?: {[string]: string}, options?: {raw?: bool, max_size?: int}) -> async.Future

Sends a request and gives a Future of its ClientResponse. Wait for one to finish before the next. Host, Accept-Encoding: gzip, User-Agent: slang and Content-Length (with a body) are added unless headers has them. Fails when the connection closes early or the response is malformed, and once the server closed the connection.

path
the request target, with the query
options
raw: true keeps a gzipped body as it came; max_size limits the inflated body (256 MiB)

HttpClient:close() -> async.Future

Closes the connection.

type ClientResponse = {status: int, reason: string, version: string, headers: {[string]: string}, body: string, compressed?: string}

What a client request resolves to. Header names are lowercase.

status: int
reason: string
version: string
headers: {[string]: string}
body: string
the whole body, inflated when the server gzipped it
compressed?: string
"gzip" or "deflate" when the body came compressed

type FetchOptions

type FetchOptions = {method?: string, headers?: {[string]: string}, body?: string, tls?: bool | table, raw?: bool, max_size?: int}

Options of fetch; every field is optional.

type MultipartParser

A multipart body parser fed chunk by chunk, for streamed uploads.

MultipartParser:push(chunk: string) -> {MultipartEvent}

Feeds the next chunk of the body; gives the events it completes (data is held back while it could be the start of a boundary). Raises when the body is malformed or a part's head is over 16 KiB.

MultipartParser:finish() -> table

Says the body has ended; raises when it ended before the closing boundary.

MultipartParser:is_done() -> bool

Whether the closing boundary has been seen.

type MultipartEvent

type MultipartEvent = {type: string, name?: string, filename?: string, content_type?: string, headers?: {[string]: string}, data?: string}

What MultipartParser.push gives, in order: a part's head, its data in pieces, its end; after the last part, the end.

type: string
"part", "data", "end_part" or "end"
name?: string
of a "part": the form field's name
filename?: string
of a "part": the file name a file field gives
content_type?: string
of a "part": text/plain when the part does not say
headers?: {[string]: string}
of a "part": its headers, names lowercase
data?: string
of a "data": a piece of the part's body

type Part

type Part = {name?: string, filename?: string, content_type: string, headers: {[string]: string}, data: string}

A part of a multipart body.

name?: string
filename?: string
given for a file field
content_type: string
text/plain when the part does not say
headers: {[string]: string}
data: string
