slang/resolve

slang/resolve: which declaration each name in a chunk refers to, and what is known about each local, before code is generated.

local info = resolve.analyse(block)
local b = info.refs[identifier_node]     // its Binding, null: a global
if(b != null and b.writes == 0){ ... }   // never assigned again

The scoping is the compiler's (see slang/codegen): a local is visible from its declaration to the end of its block, a declaration's own right side already sees it (so local func f can call itself), a local may shadow one of an enclosing scope, and a name that is no local of any enclosing function is a global. Code in quotes is data, except what an unquote (-{...}) in it computes, which runs where the quote is.

resolve.analyse(block: ast.Node) -> Info

The bindings of a parsed chunk and the binding each name in it refers to (see Info).

resolve.constant(b: Binding) -> ast.Node?

The literal a local always holds: one declared with a literal and never assigned again (by the chunk, an inner function or a pattern). Null for anything else.

type Binding

type Binding = {name: string, kind: string, node: table, value?: table, function?: table, reads: int, writes: int, captured: bool, written_inside?: bool}

A local or parameter.

name: string
kind: string
"local" (declared, also by a pattern) or "parameter"
node: table
the node that declares it (the Identifier, VarPattern or param)
value?: table
the node a local name = value declaration gives it
function?: table
the Function node it belongs to; null at the chunk's level
reads: int
the uses of its value
writes: int
the assignments after its declaration
captured: bool
an inner function uses it (it lives in an upvalue)
written_inside?: bool
an inner function assigns it

type Info

type Info = {bindings: {Binding}, refs: {[table]: Binding}, decls: {[table]: Binding}}

What analyse finds. local, by node; a name missing here is a global

bindings: {Binding}
every local and parameter, in the order they are declared
refs: {[table]: Binding}
the Identifier (or VarPattern) nodes that read or assign a
decls: {[table]: Binding}
the binding each declaring node makes, by node
