slang/peg

slang/peg: parser combinators in the style of petitparser (PEG: ordered choice, no ambiguity), the expression walker extensions add operators with, and the lossless tree that highlighting and formatting read. Grammar extensions build their syntax with it (see slang/grammar).

local peg = require("slang/peg")
local number = peg.digit():plus():flatten():trim():map(to_int)
local numbers = number:star_separated(peg.char(",")):map(func(r){
  return r.elements
})
numbers:end():parse("1, 2 ,3")      // {"ok", {1, 2, 3}}
numbers:end():parse("1, x")         // {"error", "end of input expected at 1:2"}

Every combinator is a function of peg and a method of Parser: peg.star(p) is p:star(). A parser matches at a position and produces a value: a primitive its text, seq the list of its children's values, map what its function returns, and so on. Strings are not parsers: write peg.string("if"), not "if". A parser is also a matcher in patterns: let 'numbers as local xs = "7,8" parses the whole string and matches the value.

Under the methods, a parser is a table with a parse_on function:

parser:parse_on(ctx, pos) -> new position, or -1 on failure

On success the parsed value is left in ctx.value. On failure the message and position are recorded in ctx.fail_msg / ctx.fail_pos (the last failure wins, like petitparser's choice), and the farthest failure in ctx.far_* (see Context). custom makes a parser from such a function.

A parser can also build the lossless tree of what it parsed: peg.parse_tree(parser, ctx, pos) parses like parse_on and leaves the node of the parser in ctx.tree (a Tree). A node without kids is a leaf and stands for the text it spans. Every character a parse consumes is covered by exactly one leaf, so joining the leaves gives back the input (text). Parsing for a tree is a separate path (see "the lossless tree" below), so a parse without one costs nothing extra; a parser that has no tree path of its own becomes a leaf. run with {tree: true} returns one; evaluate computes values from it in layers, highlights the highlighter's spans.

peg.node(p, start: int, stop: int, kids: {Tree}) -> Tree

A tree node, for the tree paths of custom parsers (see custom).

peg.leaf(p, start: int, stop: int) -> Tree

A leaf of the tree (no kids), for the tree paths of custom parsers.

peg.parse_tree(parser: Parser, ctx: Context, pos: int) -> int

Parses like parser:parse_on(ctx, pos) (the new position, or -1) and also leaves the node of parser in ctx.tree, with its value in node.value. For the tree paths of custom parsers; run with {tree: true} does it for a whole input.

peg.collect(ctx: Context, pos: int, tree_path: func(ctx: Context, pos: int): int) -> int

For code that runs inside a parser without a tree path while ctx.collect is set: parses with tree_path(ctx, pos) and adds the tree it left to the trees the enclosing node is woven from. Returns the new position or -1. sub is the usual way in.

peg.sub(parser: Parser, ctx: Context, pos: int) -> int

parser:parse_on(ctx, pos), for a custom parser that parses others itself. When a tree is being built, their tree becomes part of the custom parser's node (highlighting and formatting see inside it).

peg.context(buffer: string, options?: {tree?: bool}) -> Context

A fresh parse context for buffer; tree marks a context parsed with parse_tree. run and parse make their own.

peg.line_col(ctx: Context, pos: int) -> {int}

{line, column} of a byte offset, both 1-based.

peg.token_meta

The metatable of tokens, for parsers that make their own: a table {value, start, stop, buffer} with it gets line and column on demand.

peg.make_token(ctx: Context, value, start: int, stop: int) -> Token

A token for ctx's input, without a category.

primitives

peg.string(s: string, message?: string) -> Parser

Matches s exactly; its value is s.

message
the failure message, "s" expected by default

peg.char(c: string, message?: string) -> Parser

The same as string; c is usually one character.

peg.pattern(spec: string, message?: string) -> Parser

One character of a class (see slang/string's char_class): single characters and ranges, negated by a leading ^. Its value is the character. star and plus of a pattern run natively.

peg.pattern("a-zA-Z_")

peg.any(message?: string) -> Parser

Any one character (a UTF-8 sequence); fails only at the end of the input.

peg.digit(message?: string) -> Parser

returns
one character 0-9

peg.letter(message?: string) -> Parser

returns
one character a-z or A-Z

peg.word(message?: string) -> Parser

One letter, digit or underscore (not a whole word: use plus).

peg.whitespace(message?: string) -> Parser

One whitespace character; the default trimmer of trim.

peg.end_of_input(message?: string) -> Parser

Succeeds, with value null, only at the end of the input.

peg.epsilon(value?) -> Parser

Always succeeds without consuming anything; its value is value.

peg.failure(message: string) -> Parser

returns

combinators

peg.seq(...parsers: Parser) -> Parser

Each parser in turn; fails if any fails. Its value is the list of their values (a new list on every parse).

peg.choice(...parsers: Parser) -> Parser

The first parser that succeeds (ordered choice: once one matched, the others are not tried, even when what follows fails). Its value is that parser's.

peg.seq_list(parsers: {Parser}) -> Parser

returns
seq of a list

peg.choice_list(parsers: {Parser}) -> Parser

returns
choice of a list

peg.star(child: Parser) -> Parser

child zero or more times, as often as it matches (greedy, no backtracking); its value is the list of child's values. A match that consumes nothing ends the repetition.

peg.plus(child: Parser) -> Parser

child one or more times; otherwise as star.

peg.optional(child: Parser, default_value?) -> Parser

child, or nothing: when child fails it succeeds without consuming, with default_value (null by default) as its value.

peg.star_lazy(child: Parser, limit: Parser) -> Parser

child repeated until limit matches; limit is tried first at every position and is not consumed. Fails when child fails before limit matched. Its value is the list of child's values.

peg.any():star_lazy(peg.string("*/")):flatten()   // a comment's text

peg.star_separated(child: Parser, separator: Parser) -> Parser

Zero or more child separated by separator; a separator is only consumed when an element follows it. Its value is a Separated.

peg.digit():star_separated(peg.char(","))   // "1,2,3"

peg.plus_separated(child: Parser, separator: Parser) -> Parser

One or more child separated by separator; otherwise as star_separated.

peg.forbid(child: Parser, message?: string) -> Parser

Negative lookahead: succeeds, with value null, only where child fails; consumes nothing.

message
the failure where child matches, "success not expected" by default

peg.and(child: Parser) -> Parser

Lookahead: succeeds, with value null, where child succeeds; consumes nothing.

peg.neg(child: Parser, message?: string) -> Parser

Any one character where child does not match; its value is the character.

peg.char("\""):neg():star()   // the inside of a string

peg.pick(child: Parser, index: int) -> Parser

child (whose value is a list, as a seq's) with the element at index as its value; a negative index counts from the end.

peg.seq(open, body, close):pick(1)

peg.permute(child: Parser, ...indices: int) -> Parser

child (whose value is a list) with a list of the elements at indices as its value; negative indices count from the end.

peg.map(child: Parser, f: func(value): any) -> Parser

child with f(value) as its value. f runs on every match, also of alternatives that are later backtracked over, so it should not have effects; a memoized parser shares one result, so f must not change its input either.

peg.flatten(child: Parser, message?: string) -> Parser

child with the text it consumed as its value. child is parsed without building values where that can be skipped (map and where still run).

message
replaces child's failure message

peg.token(child: Parser, category?: string | func(value): string?) -> Parser

child with a Token of what it consumed as its value (its value inside). The category is what a highlighter shows (see highlights); it may be a function of child's value returning the category or null (a word that is a keyword only in some cases).

peg.trim(child: Parser, before?: Parser, after?: Parser) -> Parser

child with whatever before matches skipped in front of it and whatever after matches skipped behind it; each trimmer is applied as often as it matches. Its value is child's.

before
whitespace by default
after
before by default

peg.where(child: Parser, predicate: func(value): bool, message?: string) -> Parser

child, but only where predicate(value) is true; otherwise it fails at child's start with message ("unexpected value" by default).

ident:where(func(t){ return t.value != "end" })

peg.end(child: Parser, message?: string) -> Parser

child followed by the end of the input; its value is child's.

message
the failure when input is left, "end of input expected" by default

peg.settable(target?: Parser) -> Parser

A parser that parses with target, which Parser.set replaces later: for a grammar whose parts refer to each other.

local expr = peg.settable()
local group = peg.seq(peg.char("("), expr, peg.char(")"))
expr:set(peg.choice(group, peg.digit()))

references

peg.ref(f: func(...args): Parser, ...args) -> Parser

A lazy parser: the first time it is used (or resolved) it calls f(...args), at most four arguments, and parses with the result. Calls with the same f and arguments share one target, so a grammar written as functions that refer to each other forms a finite graph.

local func list(){
  return peg.seq(peg.char("("), peg.ref(list):star(), peg.char(")"))
}

peg.resolve(parser: Parser) -> Parser

Resolves every ref reachable from parser now and returns parser: the functions behind them run now, so keywords they register take effect now.

peg.custom(parse_on: func(self: Parser, ctx: Context, pos: int): int, parse_tree?: func(self: Parser, ctx: Context, pos: int): int) -> Parser

A parser from a raw parse function, which returns the new position and leaves its value in ctx.value, or returns fail. In a tree it is a leaf of what it consumed (with the trees of the parsers it ran through sub woven in), unless parse_tree parses and leaves its node in ctx.tree.

local upper = peg.custom(func(self, ctx, pos){
  local b = str.byte_at(ctx.buffer, pos)
  if(b != null and b >= 65 and b <= 90){
    ctx.value = str.chr(b)
    return pos + 1
  }
  return peg.fail(ctx, pos, "capital expected")
})

peg.fail(ctx: Context, pos: int, message: string) -> int

Records a failure at pos and returns -1, for custom parsers.

peg.reset_refs()

Forgets the targets ref has made, so new references call their functions again; references that were already resolved keep theirs.

running

peg.parse(parser: Parser, input: string) -> {any}

Parses input from its start: {"ok", value} or {"error", message}. It need not consume all of it: use end. The error is "message at line:column", for the failure that got furthest into the input.

peg.run(parser: Parser, input: string, options?: {tree?: bool}) -> Result

Parses input from its start, as parse does, with the details of the result or failure. With {tree: true} the result has the lossless tree.

tags

peg.tag(child: Parser, category: string) -> Parser

Parses child; its span is highlighted again under category (it wins over the tokens inside), so an extension can colour what a rule produced (an identifier as a function being declared, say) without changing the value (see highlights).

memoization

peg.memoize(p: Parser) -> Parser

Makes p remember its result per position in ctx.rule_memo, in place (every grammar sharing the parser sees it), and returns p. A grammar places these itself (see place_memos).

peg.place_memos(roots: {Parser}, named: {[Parser]: string}) -> {{parser: Parser, name: string}}

Memoizes every parser in named (the rules of a grammar and the parsers they were modified from, by name) that leads more than one alternative of a choice or dispatch reachable from roots; returns what it memoized.

peg.skip_space(ctx: Context, pos: int) -> int

The position after the slang whitespace and // comments at pos: the skip function of a walker or dispatch for slang's own trivia.

peg.dispatch(parsers: {Parser}, skip?: func(ctx: Context, pos: int): int, message?: string) -> Parser

An ordered choice over parsers that only tries, in order, the alternatives whose first byte (after skip(ctx, pos)) can match; without skip it tries them all. When no alternative can match, message (if given) is recorded as the failure. The tables are built now, from the current resolution of every rule reference, so a dispatch belongs to one sealed grammar.

walker

peg.walker(skip?: func(ctx: Context, pos: int): int) -> Walker

A new, empty expression walker. skip finds the next byte that matters (usually skip_space); with it the walker dispatches on first bytes. Register levels (tightest first), operators and primaries, then Walker.build the parser.

local w = peg.walker(peg.skip_space)
local num = peg.digit():plus():flatten():trim():map(to_int)
local func op(s){ return peg.string(s):trim() }
w:primary(num)
w:level("product"):left(op("*"), func(a, o, b){ return a * b })
w:level("sum"):left(op("+"), func(a, o, b){ return a + b })
w:build():end():parse("1 + 2 * 3")       // {"ok", 7}

the lossless tree

peg.leaves(tree: Tree?) -> {Tree}

returns
the leaves of tree in source order

peg.text(tree: Tree, buffer: string) -> string

The text of the leaves of tree, joined: the part of buffer (the input the tree was parsed from) that tree spans.

peg.tree_gap(tree: Tree) -> {at: int, leaf?: Tree}?

null when the leaves of tree cover its span exactly, in order; otherwise the position where the next leaf should have started and the leaf found there (null when the leaves end early). For testing tree paths.

layers

peg.layer(name: string, base: string) -> Layer

A custom layer starting from the built-in layer base: "text", "raw" or "default". Raises for any other base.

peg.on(parser: Parser, layer: Layer, f: func(v: Pipeline): Pipeline) -> Parser

A parser that parses like parser and carries the operations f records for layer. The parser itself is not changed: a shared parser (a rule reference, say) keeps no operations from one use. Also a method: p:on(layer, f).

local names = peg.layer("names", "raw")
local id = peg.word():plus():on(names, func(v){ return v:flatten() })

peg.mark(parser: Parser, layer: Layer, data) -> Parser

on(parser, layer, func(v){ return v:mark(data) }): data attached to the nodes of parser, read with marks. Also a method: p:mark(layer, data).

peg.marks(n: Tree, layer: Layer) -> {any}

The data marked on the node's parser for layer, in order.

peg.evaluate(tree: Tree, layer: string | Layer, buffer: string, options?: {replay?: bool}) -> any

The value of tree in layer: a built-in layer's name ("text", "raw", "default") or a layer made with layer. buffer is the input the tree was parsed from. The default layer is the value the parse produced, kept in the tree; {replay: true} computes it from the tree instead, running the functions of map and the walker again.

local r = peg.run(numbers, "4,5", {tree: true})
peg.evaluate(r.tree, "text", "4,5")   // {{"4"}, ",", {"5"}}

highlighting

peg.highlights(tree: Tree, buffer: string, options?: {trivia?: func(buffer: string, start: int, stop: int): {Span}}) -> {Span}

The tokens of a tree as a highlighter shows them, sorted and not overlapping. They come from

token(child, category)   its span (category may be a function of the
                         child's value returning a category or null)
tag(child, category)     the span of the child's value (a token, or a
                         node's token) or of the child
leaves whose parser has highlight(buffer, start, stop) -> spans
trivia: options.trivia(buffer, start, stop) -> spans (comments) for the
         leaves of trimmers (p.trivia, whitespace, a rule named
         "trivia")

An outer span wins over the ones inside it that start where it starts; the others overlapping it are dropped.

type Walker

An expression walker (see walker): a Pratt parser for operators and primaries, registered by level.

Walker:level(name?: string, placement?: Placement) -> Level

A new precedence level. Levels form a total order, tightest first; without a placement the level is looser than all so far. A level of a name already in use replaces that level. Raises when a placement names a level that does not exist.

Walker:primary(parser: Parser, name?: string, placement?: Placement) -> Walker

Adds a primary expression (what an operand can be). Primaries are tried in order, after every prefix operator and wrapper.

Walker:level_names() -> {string?}

returns
the level names, tightest first

Walker:primary_names() -> {string?}

returns
the names of the primaries, in order

Walker:prefix(operator: Parser, level: string | Level, callback: func(op, operand): any) -> Walker

A prefix operator at a level; the expression's value is what callback returns from the operator's and the operand's values.

Walker:postfix(operator: Parser, level: string | Level, callback: func(left, op): any) -> Walker

Walker:left(operator: Parser, level: string | Level, callback: func(left, op, right): any) -> Walker

A left-associative infix operator: a - b - c is (a - b) - c.

Walker:right(operator: Parser, level: string | Level, callback: func(left, op, right): any) -> Walker

A right-associative infix operator: a ^ b ^ c is a ^ (b ^ c).

Walker:wrapper(left: Parser, right: Parser, level: string | Level, callback: func(left, value, right): any) -> Walker

A whole expression between left and right, such as parentheses.

Walker:nud(operator: Parser, rbp: int, f: func(w: Walker, ctx: Context, pos: int, op): int) -> Walker

Engine API: an operator an expression can start with, at an explicit binding power. After operator matched, f parses the rest itself from pos (with Walker.parse_at), leaves the value in ctx.value and returns the new position or -1.

Walker:led(operator: Parser, lbp: int, f: func(w: Walker, ctx: Context, pos: int, left, op): int) -> Walker

Engine API: an operator that follows a value, applied when lbp is higher than the binding power being parsed; f gets the value on its left and parses the rest as for Walker.nud.

Walker:derive() -> Walker

A walker with the same registrations; changes to either do not affect the other. Build it before use.

Walker:binding_powers() -> {[string]: int}

The base binding power of every level by name (higher binds tighter), for debugging extensions.

Walker:parse_at(ctx: Context, pos: int, min_bp: int) -> int

Parses an expression whose operators bind tighter than min_bp and returns the new position or -1; the value is in ctx.value. For the callbacks of Walker.nud and Walker.led; needs Walker.build first.

Walker:parse_at_tree(ctx: Context, pos: int, min_bp: int) -> int

Walker.parse_at, also leaving the node in ctx.tree.

Walker:build() -> Parser

Builds the dispatch tables and returns the expression parser. A parser from an earlier build rebuilds the tables itself after a change; build again anyway to get a parser whose first-byte set knows the change.

A precedence level of a Walker: the walker's operator registration without naming the level. Each method returns the level.
