slang/ws

slang/ws: WebSockets (RFC 6455) on slang/async, both sides.

local async = require("slang/async")
local ws = require("slang/ws")
async.main(func(){
  local socket = async.await(ws.connect("ws://127.0.0.1:8080/live"))
  async.await(socket:send("hello"))
  local m = async.await(socket.messages:next())
  if(not m.done){ print(m.value, "\n") }
  async.await(socket:close())
})

connect is the client side; accept the server side, for slang/http's on_upgrade (slang/web's app:ws does it for you). Either gives a WebSocket: read its messages Stream, send with WebSocket.send.

Text messages must be UTF-8 (else the socket closes with 1007); a message over max_message closes it with 1009. The server requires masked frames and the client sends them; pings are answered; extensions such as compression are not negotiated.

ws.is_upgrade(req: table) -> bool

Whether a slang/http request asks to upgrade to a WebSocket (its Upgrade and Connection headers say so).

handshakes

ws.accept(req: table, conn, rest: string, options?: Options) -> WebSocket

Completes the handshake of an upgrade request and gives the server side of the WebSocket. A request that is not a WebSocket handshake (GET, version 13, with a key) gets a 400 and accept raises.

req
the slang/http request
conn
the connection on_upgrade handed over
rest
the bytes read past the request head

ws.connect(url: string, options?: Options) -> async.Future

Opens a WebSocket to a ws:// or wss:// URL: a Future of the client side WebSocket; wss uses TLS (options.tls adds slang/tls's connect options). It fails when the server does not accept the handshake. connect(host, port, path?, options?) works too.

type WebSocket

An open WebSocket connection. Its fields: messages, an async.Stream of the messages received (strings, text and binary alike) that ends when the connection does; closed, an async.Future of the CloseInfo once the connection is gone. A program may set on_pong, a function called with the data of each pong (see WebSocket.ping).

WebSocket.open: bool (read-only)

Whether messages can still be sent: false once a close has begun.

WebSocket:send(text: string) -> async.Future

Sends a text message; completes when it is written. Fails when the socket is not open.

WebSocket:send_binary(data: string) -> async.Future

Sends a binary message, as WebSocket.send does.

WebSocket:ping(data?: string) -> async.Future

Sends a ping (with up to 125 bytes of data); completes when it is written. The pong that answers it goes to socket.on_pong(data), when the socket has one.

WebSocket:close(code?: int, reason?: string) -> async.Future

Closes the connection: sends a close frame (code 1000 by default) and waits, two seconds at most, for the other side's answer. Gives the closed Future, a Future of the CloseInfo; once closing, it only returns that.

type CloseInfo

type CloseInfo = {code: int, reason: string}

How a connection ended: the close code the other side sent (1005 when none; 1006 when the connection dropped) or the one it was closed with.

code: int
reason: string

type Options

type Options = {max_message?: int, tls?: bool | table}

Options of accept and connect.

max_message?: int
the largest message in bytes (16 MiB); a larger one closes with 1009
tls?: bool | table
connect only: wss, true or slang/tls's connect options
