slang/test

slang/test: a small test framework: groups of named tests, set up and torn down, run by slang test.

local t = require("slang/test")
t.group("math"){
  t.test("adds"){
    assert(1 + 1 == 2, "1 + 1")
  }
}

A test passes when its function returns and fails when it raises (a failed assert or any other error); the report shows the message and where it was raised. Registering only collects: slang test loads the test files, then calls run_cli with its arguments, which runs everything registered and reports.

With --json, run prints one JSON object per line instead of the report: {event: "test", path, status, message, location} for each test that ran (status "passed" or "failed"; message and location when it failed), then {event: "done", passed, failed}. With --only "group / test", only the tests under that path run: a group's name, a test's, or the names from a top group down, joined by " / ".

test.group(name: string, f: function)

Registers a group: runs f at once, and the tests, groups, setups and teardowns f registers belong to the group. Usually written with a block: t.group("name"){ ... }.

test.test(name: string, f: function)

Registers a test in the current group; f runs when the tests run. Usually written with a block: t.test("name"){ ... }.

test.setup(f: function)

Registers f to run before each test and subgroup of the current group (each subgroup once, not before each of its tests).

test.teardown(f: function)

Registers f to run after each test and subgroup of the current group, whether it passed or not.

test.run(opts?: Options) -> int

Runs the registered tests, prints the report (or JSON lines) and returns the number of tests that failed.

test.run_cli(argv: {string}) -> bool

run with the options of slang test read from argv (--json, --only path; anything else is ignored); true when a test failed.
