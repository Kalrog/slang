slang/zlib

slang/zlib: deflate and inflate (zlib) in the gzip, zlib and raw formats, at once or as a stream. slang/http uses it for compressed responses.

local zlib = require("slang/zlib")
local packed = zlib.deflate("hello hello hello")
zlib.inflate(packed)  // "hello hello hello"
zlib.deflate(data, {format: "zlib", level: 9})

local c = zlib.compressor({format: "gzip"})
local out = concat(c:push("part one, "), c:push("part two"), c:finish())
c.done   // true

Formats: "gzip", "zlib", "raw", and for inflating also "auto" (gzip or zlib, told apart by the header). Errors read "zlib: ...". c is the native extension under this module.

zlib.c

The native extension: deflate(data, format, level), inflate(data, format, max_size), compressor(format, level), decompressor(format, max_size).

zlib.version() -> string

The version of the zlib library.

zlib.deflate(data: string, options?: {format?: string, level?: int}) -> string

data compressed.

zlib.inflate(data: string, options?: {format?: string, max_size?: int}) -> string

data decompressed; raises when it is not data of the format or would grow past max_size.

zlib.compressor(options?: {format?: string, level?: int}) -> Stream

A stream that compresses what is pushed (options as for deflate).

zlib.decompressor(options?: {format?: string, max_size?: int}) -> Stream

A stream that decompresses what is pushed (options as for inflate; max_size bounds the total output).

type Stream

A compressor or decompressor fed in chunks, from compressor or decompressor.

Stream:push(chunk: string) -> string

Feeds a chunk; returns what is ready of the output (maybe "").

Stream:flush() -> string

What is pending of the output, so that the receiver has all the data pushed so far.

Stream:finish() -> string

The rest of the output; the stream is done.
