slang/jwt

slang/jwt: JSON Web Tokens (RFC 7519) over slang/crypto.

local jwt = require("slang/jwt")
local token = jwt.sign({sub: "42"}, secret, {expires_in: 3600})
local claims = jwt.verify(token, secret)        // {sub: "42", iat, exp}

A key is a secret string for HS256/384/512, or a crypto.Key: RSA for RS256/384/512 and PS256/384/512, EC for ES256/384/512, Ed25519 for EdDSA. The algorithm defaults to the one that fits the key (HS256, RS256, ES256/384/512 by curve, EdDSA), and verify accepts only that one unless told otherwise, so a token cannot pick a weaker algorithm. Errors raise "jwt: ..." ("jwt: expired", "jwt: bad signature", ...).

jwt.sign(claims: Claims, key: string | crypto.Key, options?: SignOptions) -> string

A signed token with claims (copied; the options add to them). Raises when the key does not fit the algorithm, or is a public key.

jwt.decode(token: string) -> Decoded

The header and claims of a token, without checking the signature or anything else: never trust them. Raises "jwt: malformed token".

jwt.verify(token: string, key: string | crypto.Key, options?: VerifyOptions) -> Claims

The claims of a token whose algorithm is accepted, whose signature is valid for key, which has not expired and is valid already (exp and nbf, when present), and whose iss and aud match the options that ask. Raises "jwt: ..." otherwise.

local r = pcall(jwt.verify, token, public_key, {algs: {"RS256", "PS256"}})

type Claims

type Claims = {iss?: string, sub?: string, aud?: string | {string}, exp?: int, nbf?: int, iat?: int}

A token's claims: any JSON object. The registered ones sign sets and verify checks are below; times are seconds since the epoch.

iss?: string
sub?: string
aud?: string | {string}
exp?: int
when the token expires
nbf?: int
when it becomes valid
iat?: int
when it was issued; sign always sets it

type SignOptions

type SignOptions = {alg?: string, expires_in?: int, not_before?: int, issuer?: string, subject?: string, audience?: string | {string}, header?: table, now?: int}

What sign accepts besides the claims.

alg?: string
"HS256", "RS256", "ES256", "EdDSA", ... (by default the key's)
expires_in?: int
seconds from now: sets exp
not_before?: int
seconds from now: sets nbf
issuer?: string
sets iss
subject?: string
sets sub
audience?: string | {string}
sets aud
header?: table
extra header fields, such as kid
now?: int
the time in seconds since the epoch, for tests

type VerifyOptions

type VerifyOptions = {alg?: string, algs?: {string}, leeway?: int, now?: int, issuer?: string, audience?: string}

What verify checks.

alg?: string
the algorithm accepted (by default the one that fits the key)
algs?: {string}
the algorithms accepted, instead of alg
leeway?: int
seconds of clock skew allowed for exp and nbf (0)
now?: int
the time in seconds since the epoch, for tests
issuer?: string
iss must equal it
audience?: string
aud must equal it or, as a list, contain it

type Decoded

type Decoded = {header: table, claims: Claims}

A token decode read: its two JSON parts.

header: table
claims: Claims
