uv

uv: the native binding of libuv in the callback style of luv. Most code should use slang/async, which builds Futures and Streams on it.

local uv = require("uv")
local t = uv.timer()
t:start(100, 0, func(){ print("tick") t:close() })
uv.run()

Handles are userdata with methods; every operation takes its callback last, and callbacks have the shape cb(err, value) with err a string like "ECONNRESET: connection reset by peer" or null. Callbacks run only from inside uv.run(); an error raised in one stops the loop and comes out of uv.run(). An active handle (a running timer, a listening or reading socket, a pending connect) keeps its userdata alive; a handle collected before it was closed is closed by its finalizer. Failing calls raise the same kind of error text.

uv.c_api is a userdata holding the C API (slang_uv.h) through which other extensions (sqlite, crypto) run work on libuv's thread pool.

the loop

m.run(mode)

run([mode]) -> whether there is more to do; mode "default" (run until nothing is active), "once" or "nowait". Raises when the loop is already running, or with the error a callback raised.

m.stop()

stop() makes the running uv.run() return soon

m.now()

now() -> the loop's idea of the time in milliseconds

m.hrtime()

hrtime() -> a high-resolution time in nanoseconds, for measuring

m.loop_alive()

loop_alive() -> whether the loop has active, referenced handles or requests

m.version()

version() -> the libuv version text

timers

m.timer()

timer() -> a new uv.timer

tcp

m.tcp()

tcp() -> a new uv.tcp socket

pipes

m.pipe()

pipe() -> a new uv.pipe: stdin/stdout, a child's stdio, or a named pipe

signals

m.signal()

signal() -> a new uv.signal watcher

processes

m.spawn(file, args, options, cb)

spawn(file, args, options, cb) -> a uv.process running file. args is the list of arguments after the program name (or null). options (or null): cwd; env, a table of names to values replacing the environment; detached; stdio, a list for fds 0, 1, 2, ... whose entries are a uv.pipe (connected to the child), "inherit", an int (that fd of this process) or "ignore" (without stdio the child inherits 0, 1 and 2). cb(err, {status, signal}) when it exits; signal only when a signal ended it. Raises when the program cannot be started.

m.kill(pid, sig)

kill(pid, [sig]) sends sig (a number or a name, "SIGTERM" by default) to the process pid

m.getpid()

getpid() -> the id of this process

polling

m.poll(fd)

poll(fd) -> a uv.poll watching a socket or pipe that another library owns (a database client, say)

names

m.getaddrinfo(host, port, family, cb)

getaddrinfo(host, [port], [family], cb) resolves host; cb(err, list of {ip, port, family}). port is a number, a service name or null; family "ipv4" or "ipv6" limits the answers.

files

m.fs_read_file(path, cb)

fs_read_file(path, cb) reads the whole file; cb(err, data)

m.fs_write_file(path, data, append, cb)

fs_write_file(path, data, [append], cb) creates or replaces the file, or appends to it when append is true; cb(err)

m.fs_stat(path, cb)

fs_stat(path, cb) -> cb(err, {size, mode, mtime, atime, ctime, is_file, is_dir}); the times in seconds

m.fs_unlink(path, cb)

fs_unlink(path, cb) removes a file; cb(err)

m.fs_mkdir(path, cb)

fs_mkdir(path, cb) makes a directory; cb(err)

m.fs_rmdir(path, cb)

fs_rmdir(path, cb) removes an empty directory; cb(err)

m.fs_rename(from, to, cb)

fs_rename(from, to, cb) renames a file or directory; cb(err)

m.fs_scandir(path, cb)

fs_scandir(path, cb) lists a directory; cb(err, list of {name, type}) with type "file", "dir", "link", "unknown" or "other"

m.fs_open(path, flags, cb)

fs_open(path, flags, cb) opens a file; cb(err, fd). flags as in fopen: "r", "r+", "w", "w+", "a", "a+", and "wx" or "w+x" to fail when the file exists.

m.fs_read(fd, length, offset, cb)

fs_read(fd, length, offset, cb) -> cb(err, data); offset -1 or null reads at the current position. data is shorter at the end of the file, "" past it.

m.fs_write(fd, data, offset, cb)

fs_write(fd, data, offset, cb) writes all of data at offset (-1 or null: the current position); cb(err, written)

m.fs_close(fd, cb)

fs_close(fd, cb) closes a file descriptor; cb(err)

type uv.timer

uv.timer:start(timeout, repeat, cb)

timer:start(timeout, repeat, cb) calls cb() after timeout milliseconds, then every repeat milliseconds unless repeat is 0 (or null)

uv.timer:stop()

timer:stop() stops the timer

uv.timer:again()

timer:again() restarts a repeating timer with its repeat interval

uv.timer:close(cb)

timer:close([cb]) closes the handle; cb() runs once it is closed

uv.timer:is_active()

timer:is_active() -> whether the timer is running

uv.timer:is_closing()

timer:is_closing() -> whether close() was called

uv.timer:ref()

timer:ref() makes the handle keep uv.run() going again (the default)

uv.timer:unref()

timer:unref() makes the handle no longer keep uv.run() going

uv.timer:has_ref()

timer:has_ref() -> whether the handle keeps uv.run() going

tcp:bind(ip, port) binds the socket to an IPv4 or IPv6 address (not a host name)

tcp:listen([backlog], cb) listens for connections (backlog 128, pass null for it); cb(err) runs for each one, which accept() then takes

tcp:accept(client) accepts a pending connection into client, a new uv.tcp or uv.pipe

uv.tcp:getpeername()

tcp:getpeername() -> {ip, port, family} of the remote end

uv.tcp:nodelay(enable)

tcp:nodelay(enable) turns Nagle's algorithm off (true) or on

uv.tcp:keepalive(enable, delay)

tcp:keepalive(enable, [delay]) turns TCP keep-alive on or off; delay is the initial delay in seconds (60)

uv.tcp:fileno()

uv.tcp:close(cb)

tcp:close([cb]) closes the handle; cb() runs once it is closed

uv.tcp:is_active()

uv.tcp:is_closing()

tcp:is_closing() -> whether close() was called

uv.tcp:ref()
