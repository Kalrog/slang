uv

uv: the native binding of libuv in the callback style of luv. Most code should use slang/async, which builds Futures and Streams on it.

local uv = require("uv")
local t = uv.timer()
t:start(100, 0, func(){
  print("tick\n")
  t:close()
})
uv.run()

Handles (Timer, Tcp, Pipe, Signal, Process, Poll) are userdata with methods; every operation takes its callback last, and callbacks have the shape cb(err, value) with err a string like "ECONNRESET: connection reset by peer" or null. Callbacks run only from inside run; an error raised in one stops the loop and comes out of run. An active handle (a running timer, a listening or reading socket, a pending connect) keeps its userdata alive; a handle collected before it was closed is closed by its finalizer. Failing calls raise the same kind of error text.

Every VM has a loop of its own, so isolates (slang/isolate) run event loops side by side; handles cannot cross between them, and what an isolate leaves open is closed with its loop when it ends. Killing an isolate wakes its loop: run raises "isolate killed".

uv.c_api is a userdata holding the C API (slang_uv.h) through which other extensions (sqlite, crypto) run work on libuv's thread pool.

the loop

uv.run(mode?: string) -> bool

Runs the event loop and returns whether there is more to do. Raises when the loop is already running, or with the error a callback raised.

mode
"default" (run until nothing is active), "once" or "nowait"

uv.stop()

Makes the running run return soon.

uv.now() -> int

The loop's idea of the time in milliseconds.

uv.hrtime() -> int

A high-resolution time in nanoseconds, for measuring.

uv.loop_alive() -> bool

Whether the loop has active, referenced handles or requests.

uv.version() -> string

The libuv version text.

timers

uv.timer() -> Timer

A new timer, not started.

tcp

uv.tcp() -> Tcp

A new TCP socket, neither bound nor connected.

pipes

uv.pipe() -> Pipe

A new pipe: for stdin/stdout (Pipe.open), a child's stdio (spawn) or an accepted connection.

signals

uv.signal() -> Signal

A new signal watcher, not started.

async handles

uv.async(cb: func()) -> Async

A handle whose cb runs on the loop after a wake from any thread: another extension sends it through the C API (slang_uv.h's async_send), and an isolate's channel through [isolate.Channel.watch]. Several wakes before cb runs make one call. It keeps run going until it is closed.

processes

uv.spawn(file: string, args: {string}?, options: SpawnOptions?, cb: func(err: Err, exit: ExitStatus)) -> Process

Starts file (looked up on the PATH) and calls cb when it exits. Raises when the program cannot be started.

args
the arguments after the program name, or null

uv.kill(pid: int, sig?: int | string)

Sends sig (a number or a name, "SIGTERM" by default) to the process pid.

uv.getpid() -> int

The id of this process.

polling

uv.poll(fd: int) -> Poll

A watcher of a socket or pipe that another library owns (a database client, say), not started.

names

uv.getaddrinfo(host: string, port: int | string | null, family: string?, cb: func(err: Err, addresses: {Address}))

Resolves host.

port
a number, a service name or null
family
"ipv4" or "ipv6" limits the answers; null gives both

files

uv.fs_read_file(path: string, cb: func(err: Err, data: string?))

Reads the whole file.

uv.fs_write_file(path: string, data: string, append: bool?, cb: func(err: Err))

Creates or replaces the file, or appends to it when append is true.

uv.fs_stat(path: string, cb: func(err: Err, stat: FileStat?))

Reads what the file system knows about path.

uv.fs_unlink(path: string, cb: func(err: Err))

Removes a file.

uv.fs_mkdir(path: string, cb: func(err: Err))

Makes a directory.

uv.fs_rmdir(path: string, cb: func(err: Err))

Removes an empty directory.

uv.fs_rename(from: string, to: string, cb: func(err: Err))

Renames a file or directory.

uv.fs_scandir(path: string, cb: func(err: Err, entries: {DirEntry}?))

Lists a directory.

uv.fs_open(path: string, flags: string, cb: func(err: Err, fd: int?))

Opens a file and gives its descriptor.

flags
as in fopen: "r", "r+", "w", "w+", "a", "a+", and "wx" or "w+x" to fail when the file exists

uv.fs_read(fd: int, length: int, offset: int?, cb: func(err: Err, data: string?))

Reads up to length bytes at offset. data is shorter at the end of the file, "" past it.

offset
-1 or null reads at the current position

uv.fs_write(fd: int, data: string, offset: int?, cb: func(err: Err, written: int?))

Writes all of data at offset.

offset
-1 or null writes at the current position

uv.fs_close(fd: int, cb: func(err: Err))

Closes a file descriptor.

type Timer

A timer; type() of it is "uv.timer".

Timer:start(timeout: int, repeat: int?, cb: func())

Calls cb() after timeout milliseconds, then every repeat milliseconds unless repeat is 0 or null.

Timer:stop()

Stops the timer.

Timer:again()

Restarts a repeating timer with its repeat interval.

Timer:close(cb?: func())

Closes the handle; cb() runs once it is closed.

Timer:is_active() -> bool

Whether the timer is running.

Timer:is_closing() -> bool

Whether Timer.close was called.

Timer:ref()

Makes the handle keep run going again (the default).

Timer:unref()

Makes the handle no longer keep run going.

Timer:has_ref() -> bool

Whether the handle keeps run going.

type Tcp

A TCP socket, listening or connected; type() of it is "uv.tcp".

Tcp:bind(ip: string, port: int)

Binds the socket to an IPv4 or IPv6 address (not a host name).

Tcp:listen(backlog: int?, cb: func(err: Err))

Listens for connections; cb(err) runs for each one, which Tcp.accept then takes.

backlog
the queue length, 128 when null

Tcp:accept(client: Tcp | Pipe)

Accepts a pending connection into client, a new Tcp or Pipe.

Tcp:connect(ip: string, port: int, cb: func(err: Err))

Connects to an IPv4 or IPv6 address (not a host name; see getaddrinfo); cb(err) when done.

Tcp:read_start(cb: func(err: Err, chunk: string?))

Starts reading: cb(err, chunk) for each chunk, with chunk null at the end of the stream. Reading stops at the end or an error.

Tcp:read_stop()

Stops reading.

Tcp:write(data: string, cb?: func(err: Err))

Queues a copy of data; cb(err) once it is written.

Tcp:shutdown(cb?: func(err: Err))

Closes the write side after pending writes; cb(err) when done.

Tcp:getsockname() -> Address

The local end of the socket.

Tcp:getpeername() -> Address

The remote end of the socket.

Tcp:nodelay(enable: bool)

Turns Nagle's algorithm off (true) or on.

Tcp:keepalive(enable: bool, delay?: int)

Turns TCP keep-alive on or off.

delay
the initial delay in seconds, 60 by default

Tcp:fileno() -> int

The OS file descriptor.

Tcp:close(cb?: func())

Closes the handle; cb() runs once it is closed.

Tcp:is_active() -> bool

Whether the socket is listening, reading or connecting.

Tcp:is_closing() -> bool

Whether Tcp.close was called.

Tcp:ref()

Makes the handle keep run going again (the default).

Tcp:unref()

Makes the handle no longer keep run going.

Tcp:has_ref() -> bool

Whether the handle keeps run going.

type SpawnOptions

type SpawnOptions = {cwd?: string, env?: {[string]: string}, detached?: bool, stdio?: {Pipe | string | int}}

How spawn starts a program.

cwd?: string
the directory to run in
env?: {[string]: string}
the whole environment of the child, replacing this process's
detached?: bool
runs the child in its own process group
stdio?: {Pipe | string | int}
fds 0, 1, 2, ...: a Pipe (connected to the child), "inherit", an int (that fd of this process) or "ignore"; without stdio the child inherits 0, 1 and 2

How a child process ended.

signal?: string | int
the signal that ended it (a name, or the number when it has none here); null when it exited
