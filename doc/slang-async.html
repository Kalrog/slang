slang/async

slang/async: Futures, Streams and await on coroutines, driven by the uv event loop (the native uv module). Callback style and await style mix:

local async = require("slang/async")
async.main(func(){
  local conn = async.await(async.connect("127.0.0.1", 8080))
  async.await(async.write(conn, "hello\n"))
  local reader = async.reader(conn)
  for(true){
    local r = async.await(reader:next())
    if(r.done){ break }
    print(r.value)
  }
})

The extension extensions/async adds async func, await and await for on top of this module.

A Future completes once, with a value or an error (any value; errors raised inside async functions are the error tables pcall produces). A Stream is a sequence of values ending with done or an error; next() gives the next event as a Future, listen consumes it with a callback.

await(f) must be called from a coroutine started by async.run (an "async function"). It registers a waiter that reschedules the coroutine and yields; a completed Future returns immediately without yielding. Waiters run from the loop (a zero timer), never inside the code that completed the Future, so completing a Future never re-enters the completer.

futures

async.completer()

completer() -> {future, complete(value), fail(error)}

async.value(v)

No description.

async.failed(e)

No description.

async.wrap(start)

wrap(start) -> Future: start(cb) begins an operation whose callback has the uv shape cb(err, value); the future fails with err or completes with value

async.all(futures)

all(futures) -> Future of the list of values (fails with the first error)

async.race(futures)

race(futures) -> Future that settles like the first of the futures to settle; the others are marked handled and their results dropped

async.timeout(f, ms, message)

timeout(f, ms, message) -> Future of f's value, or failing with message ("timed out after <ms> ms" by default) when f takes longer than ms milliseconds (an error keeps only its message through raise, so tell a timeout by the message you chose)

await and run

async.await(f)

await(f) -> the value of f, or raises its error

async.run(f)

run(f) -> Future: runs f in a coroutine that may await; the future completes with f's return value or fails with its error

async.sleep(ms)

sleep(ms) -> Future that completes after ms milliseconds

async.set_driver(step)

set_driver(step) replaces the driver; null restores libuv's

async.main(f)

main(f) -> the value of f: runs f as an async function and drives the event loop until it finishes. Failed futures nobody handled are reported.

streams

async.controller(options)

controller() -> {stream, add(value), close(), fail(error)}; on_pause and on_resume on the controller are called when the buffer passes high_water and when a reader drains it (backpressure)

async.pull(next_value)

No description.

async.iterator(s)

iterator(stream) -> a function returning the next value, or null at the end (what await for loops over: a for-in loop calls it until the pattern stops matching, so a null value ends the loop early)

tcp adapters

async.resolve(host, port, family)

resolve(host, port, family) -> Future of the list of {ip, port, family} the name resolves to; family "ipv4" or "ipv6" limits it

async.connect(host, port)

connect(host, port) -> Future of a connected uv.tcp handle; a host name is resolved first and its addresses tried in order

async.write(handle, data)

write(handle, data) -> Future

async.shutdown(handle)

shutdown(handle) -> Future; close(handle) -> Future

async.close(handle)

No description.

async.reader(handle, options)

reader(handle) -> Stream of chunks (reading pauses when the consumer falls behind and resumes when it catches up)

async.serve(host, port, options)

serve(host, port, options) -> {server, connections, close()}: a listening socket and a Stream of accepted uv.tcp handles; close() stops listening and ends the stream

files

async.fs

The file system on libuv's thread pool; every function returns a Future. Errors read like "ENOENT: no such file or directory, read_file 'x'".

fs.read_file(path) -> the contents    fs.write_file(path, data)
fs.append_file(path, data)            fs.exists(path) -> bool
fs.stat(path) -> {size, mode, mtime, atime, ctime, is_file, is_dir}
fs.list_dir(path) -> list of {name, type}   (type "file", "dir", ...)
fs.remove(path)   fs.mkdir(path)   fs.rmdir(path)   fs.rename(from, to)
fs.open(path, flags) -> fd   (flags as fopen: "r", "w", "a", "r+", ...)
fs.read(fd, length, offset) -> data ("" at the end; offset null reads on)
fs.write(fd, data, offset) -> bytes written   fs.close(fd)
fs.read_stream(path, {chunk_size, start, length}) -> a Stream of the file, read on demand

signals

async.on_signal(name, f)

on_signal(name, f) -> the uv.signal handle: f(name) runs each time the process gets the signal ("SIGINT", "SIGTERM", ...). The handle does not keep the loop running; stop() or close() it when done.

processes

async.spawn(file, args, options)

spawn(file, args, options) -> {process, pid, stdin, stdout, stderr, pipes, exit, kill(sig)}: starts a program. options as for uv.spawn (cwd, env, detached), except that a stdio entry "pipe" makes a pipe: the ones for fds 0, 1 and 2 are stdin, stdout and stderr, all of them are in pipes by fd. Without stdio the child inherits 0, 1 and 2. exit is a Future of {status, signal}. Raises when the program cannot be started.

async.exec(file, args, options)

exec(file, args, options) -> Future of {status, signal, stdout, stderr}: runs a program to the end and collects its output. options.input is written to its stdin (otherwise stdin is empty); cwd and env as for spawn.
