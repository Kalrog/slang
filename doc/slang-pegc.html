slang/pegc

pegc: compiles a sealed peg grammar (slang/grammar) into slang source.

local pegc = require("slang/pegc")
local c = pegc.compile(g)        // g: a grammar that has parsed (sealed)
c.source                         // the generated parser as slang
local parsers = c:load()         // {rules, trees, fasts}: by rule name
parsers.rules.statement(ctx, 0)  // as parser:parse_on(ctx, 0)

The combinators of slang/peg interpret the grammar; this generates the code they would run for it, once. Every parser node reachable from the grammar's rules becomes straight-line code inlined into its parent, except nodes that are shared (several parents, rules, memoized nodes, dispatch candidates), which become functions. Each node is generated in the mode its parent needs: the value path, the fast path that only finds the end position (under flatten and lookaheads), or the tree path that also builds the lossless tree (ctx.tree, for the language server and the formatter). Actions (map, where), custom parsers, regexes and the walker's callbacks stay what they are and are called through a table of statics. The generated code keeps the context contract of slang/peg (ctx.value, the farthest failure, rule_memo, skip_from/skip_to), so it reports the same failures and builds the same ASTs; only peg's "last failure" (ctx.fail_pos, ctx.fail_msg), which the grammar's parse never reads, is not recorded.

The grammar installs the generated parsers as the targets of its rule references (see slang/grammar), so every parse under a grammar that was generated runs them, the tree parse included.
