slang/web

slang/web: the application layer on slang/http: routes, middleware, request helpers, responses, static files, sessions, CSRF protection, WebSocket routes and a test client.

local async = require("slang/async")
local web = require("slang/web")
local app = web.app()
app:use(web.sessions({secret: "at least sixteen characters"}))
app:get("/todos/:id", func(req, params){ return web.json({id: params.id}) })
app:post("/upload", handler, {stream_body: true})
app:static("/static", "public", {max_age: 3600})
app:ws("/live", func(socket, req, params){ socket:send("hello") })
app.fallback = func(req){ return web.text("nothing here", 404) }
async.main(func(){ async.await(app:listen("127.0.0.1", 8080).done) })

Handlers and middleware run inside a coroutine, so they may await. A Handler gets (req, params) and returns a string (text/plain), an HTML node from slang/html (text/html), a response table {status, headers, body}, or a Future of one of those. A Middleware gets (req, next): next(req) runs the rest of the chain and returns its response, normalized (a table with status, headers and body), so middleware can look at it and change it.

An error in a handler becomes a 500 (and app.on_error(req, err) runs, printing to stderr by default); fail raises an error that becomes the response it names instead. A path that matches routes of other methods only is answered 405 with Allow; HEAD runs the GET route.

Requests are slang/http's request tables with the methods of Request (query_params, cookie, form, json) and req.params. test runs an app without a socket:

local client = web.test(app)
local res = async.await(client:post("/login", {form: {user: "ann"}}))
print(res.status, res:header("location"))

responses

web.text(s: string, status?: int) -> http.Response

A text/plain response (200 by default).

web.html(content: string | table, status?: int) -> http.Response

A text/html response (200 by default) of an HTML string or a slang/html node, which is rendered.

web.json(value, status?: int) -> http.Response

An application/json response (200 by default) of value encoded.

web.redirect(url: string, status?: int) -> http.Response

A redirect to url: 303 See Other by default (the browser follows with a GET); 301, 302, 307 or 308 when asked.

web.fail(status: int, message?: string)

Raises an error the app answers with status and the message as text (the status's reason phrase by default), instead of a 500. on_error is not called for it.

if(todo == null){ web.fail(404, "no such todo") }

routes

web.app(options?: table) -> WebApp

A new application with no routes.

options
kept as app.options; the app itself uses none

static files

web.mime_type(path: string) -> string

The media type for the file's extension, like "text/css; charset=utf-8"; application/octet-stream when it is not known.

web.file(req: Request, path: string, options?: FileOptions) -> async.Future

A Future of a response sending the file: 404 when it is not a file; ETag and Last-Modified, 304 for conditional requests, a single byte Range (206, 416). The body is streamed from disk (or the bundle of a built program; a file bundled gzipped goes as it is to a client that takes gzip).

app:get("/report", func(req){ return web.file(req, "out/report.pdf") })

sessions

web.sessions(options: SessionOptions) -> Middleware

Sessions in a cookie: req.session is a table kept in an encrypted cookie (AES-GCM, so the client can read nothing and change nothing), saved when it changed (as JSON) and dropped when empty. Raises without a good secret, and when a session grows too large for a cookie.

app:use(web.sessions({secret: os.getenv("SESSION_SECRET")}))
app:post("/login", func(req){
  req.session.user = req:form().user
  return web.redirect("/")
})

CSRF

web.csrf(options?: CsrfOptions) -> Middleware

CSRF protection: unsafe requests (POST, PUT, PATCH, DELETE) must send the token req.csrf_token holds back, as the X-CSRF-Token header or the _csrf field of a urlencoded form; others get a 403. The token lives in an HttpOnly SameSite=Lax cookie. Add it after sessions and put req.csrf_token in your forms.

web.test(app: WebApp) -> WebTestClient

type Request

A request as handlers and middleware see it: an http.Request with these methods. The app adds params (the route's :name parts, and the * part as rest); middleware may add more (session, csrf_token).

Request:query_params() -> {[string]: string}

The query string decoded (req.query is the raw text).

Request:cookie(name: string) -> string?

The value of the request's cookie name, or null.

Request:form() -> {[string]: any}

The fields of a form body: urlencoded (or no Content-Type) or multipart/form-data, where a file field is {filename, content_type, data}. Fails with 415 for other types, and with 400 for a multipart body that was streamed.

Request:json()

Fails with 400 when the body is not JSON.

returns
the decoded JSON body

type Handler

type Handler = func(req: Request, params: {[string]: string}): any

What a route runs: it returns a string, a slang/html node, an http.Response or a Future of one of those.

type Middleware

type Middleware = func(req: Request, next: func(req?: Request): http.Response): any

What WebApp.use takes: next(req) runs the rest of the chain (with req, or the one given) and returns its normalized http.Response.

type WebApp

An application: routes and middleware, served by WebApp.listen. app.fallback, a func(req), answers requests no route matches (404 by default); app.on_error(req, err) is told of errors that became a 500 (it prints to stderr by default).

WebApp:use(middleware: Middleware) -> WebApp

Adds a middleware; they run in the order added, around every route (WebSocket routes included) and the fallback.

WebApp:route(method: string, pattern: string, handler: Handler, options?: RouteOptions) -> WebApp

Adds a route. A pattern is a path whose parts may be :name (one non-empty part, decoded into params.name) or a last * (the rest of the path, into params.rest). The first route added that matches wins.

app:route("GET", "/files/:user/*", func(req, params){
  return concat(params.user, " wants ", params.rest)
})

WebApp:get(pattern: string, handler: Handler, options?: RouteOptions) -> WebApp

WebApp.route for GET.

WebApp:post(pattern: string, handler: Handler, options?: RouteOptions) -> WebApp

WebApp.route for POST.

WebApp:put(pattern: string, handler: Handler, options?: RouteOptions) -> WebApp

WebApp.route for PUT.

WebApp:patch(pattern: string, handler: Handler, options?: RouteOptions) -> WebApp

WebApp.route for PATCH.

WebApp:delete(pattern: string, handler: Handler, options?: RouteOptions) -> WebApp

WebApp.route for DELETE.

WebApp:ws(pattern: string, handler: func(socket: table, req: Request, params: {[string]: string}), options?: {max_message?: int}) -> WebApp

Adds a WebSocket route: a matching upgrade request (after the middleware) is accepted and handler gets the slang/ws socket. An error the handler raises closes the socket with 1011. The first matching route wins; a request no route matches gets a 404.

options
as for slang/ws's accept

WebApp:stream_body(req: http.Request) -> bool

Whether the route for req says stream_body: true; what WebApp.listen gives slang/http as its stream_body.

WebApp:handle(req: http.Request) -> async.Future

Runs the app for a request: a Future of the normalized http.Response (it does not fail; errors become responses). The slang/http handler of the app, and what test calls.

WebApp:upgrade(req: http.Request, conn, rest: string)

Handles a request for another protocol (slang/http's on_upgrade): a matching WebApp.ws route, after the middleware, gets a WebSocket; otherwise the connection is answered (404, or what the middleware returned) and closed.

WebApp:listen(host: string, port: int, options?: http.ServeOptions) -> http.Server

Serves the app with http.serve. stream_body is the route's (or yours, when it says true) and on_upgrade is the app's.

WebApp:static(prefix: string, dir: string, options?: FileOptions) -> WebApp

Serves the files under dir at prefix, as file does: "/static/a/b.css" for prefix "/static" is dir/a/b.css. Paths with "..", "." or empty parts, backslashes or NULs get a 404.

type WebTestClient

A client that runs requests through an app without a socket, keeping cookies across requests: client.cookies holds their values by name (a test may read and change it), sent to the paths their Path allows. Domain is not looked at: the client talks to one app.

WebTestClient:request(method: string, path: string, options?: TestOptions) -> async.Future

Runs a request through the app: a Future of the TestResponse. path may carry a query. The client's cookies are sent and the Set-Cookie headers of the response remembered.
