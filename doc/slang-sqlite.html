slang/sqlite

slang/sqlite: SQLite with an API that reads well, on the native sqlite extension. The sql{ ... } literals of extensions/sqlite produce the query values; plain SQL text with a parameter list works as well.

local db = sqlite.open("todos.db")            // or ":memory:"
db:exec("create table if not exists todos(id integer primary key, text text, done boolean)")
db:run(sql{ insert into todos(text, done) values ({text}, {false}) })  -> {changes, last_id}
db:all(sql{ select * from todos where done = {done} })  -> rows, tables by column name
db:one(sql{ select * from todos where id = {id} })      -> a row or null
for(let {id: local id, text: local text} in db:each(sql{ select id, text from todos })){ ... }
db:transaction(func(){ ... })   commits, or rolls back when the function raises
db:all("select * from todos where id > ?", {5})          the same without the syntax
db:close()

Queries: sqlite.query(text, values, origin, count) holds the text with one ? per value and the values (count says how many, since a null value ends a list literal's length; it defaults to len(values)); a value made with sqlite.list(items) expands to ?, ?, ... (an empty list to null, which matches nothing), a value that is itself a query is spliced in with its parameters, so fragments compose safely. Prepared statements are cached per database by text. Errors name the literal: "sqlite: no such table: todo (at views.slang:12)".
