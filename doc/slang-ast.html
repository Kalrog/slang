slang/ast

slang/ast: building, checking and printing the syntax tree that the parser produces, quotes (+{...}) build and extensions return.

local ast = require("slang/ast")
local sum = ast.node("BinOp", {
  left: ast.literal(null, 1), op: "+", right: +{x * 2},
})
print(ast.to_source(sum))        // 1 + x * 2

A node is a table {type: "Name", ...fields, token} whose metatable has __type == "Name": type(node) is "Name", and patterns like 'BinOp{left: local l} match it. Each node type has a fixed set of fields, listed in specs. Quoted code (+{...}) and the code extensions generate have exactly the same shape, so an extension may return either; a plain table in node shape ({type: "Identifier", value: "x"}) is accepted too wherever a parser result goes through decode.

ast.specs

The fields of every node type, in order, as {name, kind} pairs: specs.BinOp is {{"left", "node"}, {"op", "value"}, {"right", "node"}}. The kinds: "node" (a child node), "node?" (an optional child), "list" (a list of child nodes) and "value" (a string, number or bool). A type not listed here is not a node type.

ast.node(type_name: string, fields: table, token?: table) -> Node

Makes fields a node of type type_name, in place, and returns it. Raises for an unknown node type; the fields are not checked against specs.

ast.node("Identifier", {value: "x"}, null)

ast.is_node(value) -> bool

Whether value is a node with its metatable. A plain table in node shape is not; decode makes it one.

ast.is_statement(node: Node?) -> bool

Whether node may stand as a statement (a Block, If, Declaration, CallStat, Unquote, ...); false for null and for expressions.

ast.is_assignable(node: Node) -> bool

Whether node may be assigned to: an Identifier, an Index or an Unquote.

ast.is_literal(node: Node) -> bool

Whether node is a constant: Int, Double, String, True, False or Null.

ast.requires(node: Node) -> Requires

The modules the code requires: those given by a constant name (require("a/b")) and the places of those whose name is computed. Quoted code is not looked into; positions are 0 for generated nodes.

ast.literal(token: table?, value) -> Node

The node for a string, int, double, bool or null value; raises for any other type.

ast.resolve_escapes(literal: string) -> string

The text of a string literal's body with its escape sequences replaced: \n \r \t \b \f \v \\ \" and \xHH (a byte), \u{H...} (a code point, as UTF-8). Raises on any other escape.

ast.resolve_escapes("a\\nb")   // "a", a newline, "b"

quote support

ast.quote(node: Node) -> Node

The Table literal expression that rebuilds node at run time (what +{...} compiles to). An Unquote inside becomes the expression it holds, so its value is spliced in.

ast.strip(node: Node?) -> Node?

A copy of the tree without tokens. A value that is not a node is returned as it is.

ast.attach_token(node: Node?, token: table?) -> Node?

Gives every node of the tree that has no token this one, in place, and returns node; generated code then reports errors at token.

ast.decode(value: Node | {token: table, ast: Node} | null) -> Node?

The node an extension's parser or callback produced: a node; a {token, ast} pair, whose token goes to every node of ast that has none (see attach_token); or a plain table in node shape, which gets its metatable. Raises for anything else.

to_string

ast.to_string(node: Node) -> string

The tree in a compact debugging form: expressions fully parenthesized, (1 + (x * 2)). Not meant to be parsed again; see to_source.

to_source

ast.to_source(node: Node) -> string

slang source for a tree, ending with a newline: what a file looks like once its extensions have been applied (every extension lowers to the core AST). Parsing the result gives the same bytecode again. A Block at the top is printed as a chunk (no braces); a statement or an expression as itself, with parentheses only where precedence needs them.

type Node

type Node = {type: string, token?: table}

A syntax tree node. Its other fields depend on its type (see specs).

type: string
the node type: "Identifier", "BinOp", "Call", "Block", ...
token?: table
its source token (see slang/peg); null in generated code

type Requires

type Requires = {names: {{name: string, pos: int}}, computed: {int}}

What requires finds.

names: {{name: string, pos: int}}
each require of a constant name, with the byte offset of the call
computed: {int}
the byte offsets of the requires whose name is computed
