sqlite

sqlite: the native binding of SQLite, as thin as it is useful. Most code should use slang/sqlite, which builds the friendly API on it.

local sqlite = require("sqlite")
local db = sqlite.open("todos.db")  // or ":memory:"
db:exec("create table t(id integer primary key, name text)")
local st = db:prepare("insert into t(name) values (?)")
st:bind_all({"ada"}) st:step() st:reset()
local q = db:prepare("select * from t where id > ?")
q:bind(1, 0)
for(q:step()){ print(q:row().name, "\n") }

Values: null, bool (bound as 0/1), int, double, string (text; a blob column also comes back as a string). A column declared boolean (or bool) is read as true/false. A statement is linked to its database: closing the database finalizes its statements, and a finalized statement raises on use. Errors read "sqlite: ...".

sqlite.open(path: string) -> Database

Opens a database file, created when missing; ":memory:" opens a database in memory. Raises when it cannot be opened.

sqlite.version() -> string

The version of the SQLite library ("3.46.0").

type AsyncResult

type AsyncResult = {rows: {{[string]: any}}, changes: int, last_insert_rowid: int}

What Statement.run_async gives its callback.

rows: {{[string]: any}}
the rows, tables by column name

type Database

An open database connection.

Database:exec(sql: string)

Runs one or more statements without parameters, discarding any rows.

Database:prepare(sql: string) -> Statement

A statement for the first statement in sql, with ? for its parameters; raises when the text holds no statement.

Database:close()

Finalizes the statements and closes the database; raises while queries started with Statement.run_async are running.

Database:is_open() -> bool

Whether the database is still open.

Database:changes() -> int

The number of rows the last insert, update or delete changed.

Database:last_insert_rowid() -> int

The rowid of the last inserted row.

type Statement

A prepared statement of a Database.

Statement:bind(i: int, value) -> Statement

Binds parameter i (counting from 1) to value; returns the statement.

Statement:bind_all(values: {any}, count?: int) -> Statement

Binds all parameters in order; returns the statement. Raises unless count equals the number of parameters.

count
how many values (len(values)); a null value ends a list's length

Statement:step() -> bool

Runs the statement to its next row: true when a row is ready, false when the statement is done.

Statement:row() -> {[string]: any}

The current row by column name.

Statement:values() -> {any}

The current row's values, in column order.

Statement:columns() -> {string}

The column names, in order.

Statement:parameter_count() -> int

The number of parameters.

Statement:reset() -> Statement

The statement, ready to run again, with its bindings cleared.

Statement:finalize()

Frees the statement; using it afterwards raises.

Statement:run_async(cb: func(err: string?, result: AsyncResult?))

Runs the bound statement to the end on libuv's thread pool and calls cb from the loop. Until then the statement is busy: using it raises and the database cannot be closed.

Statement:is_busy() -> bool

Whether a Statement.run_async query is still running it.
