slang/ast

slang/ast: helpers for AST nodes.

A node is a table {type: "Name", ...fields, token} whose metatable has __type == "Name", so patterns like 'BinOp{left: local l} match it. The field layout follows the table encoding of the original implementation, so quoted code (+{...}) and extension-generated code use exactly the same shape.
