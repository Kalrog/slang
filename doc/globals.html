globals

globals: the functions every slang program has without a require, built into the VM.

local f = open("notes.txt", "w")
f:write(concat("args: ", len(args()), "\n"))
f:close()
for(let local e in entries({a: 1, b: 2})){ print(e[0], "=", e[1], "\n") }

Errors are values: error raises one, pcall catches it as an Error table, raise passes it on. Tables are both lists (keys 0..n-1) and maps; keys, values and entries iterate them with list indices first, then the other keys in insertion order. require, module and run are globals too, written in slang (slang/lib/package.slang and slang/std); compile is in slang/compiler/compiler.slang.

input and output

print(...values)

Writes the values to standard output without separators: strings as they are, other values as string renders them. Output is buffered and flushed when a value contains a newline.

readLine() -> string?

The next line of standard input without its line ending, or null at the end of the input. Flushes standard output first.

args() -> {string}

The command-line arguments of the program.

open(path: string, mode?: string) -> File

Opens a file. A missing file is created first, together with its directory, whatever the mode. Raises "cannot open <path>" when the file cannot be opened.

mode
"r" (the default) to read, "w" to write (truncating), "a" to append, "rw" to read and write (truncating), "ra" to read and append local f = open("out.txt", "w") f:write("hello\n") f:close()

errors

assert(cond, ...message)

Raises an error when cond is null or false. The message is the remaining values written one after the other, or "assertion failed" without them.

assert(len(list) > 0, "empty list for ", name)

error(...values)

Raises an error whose message is the values rendered and joined as print does.

error("Package not found: ", name)

raise(err: Error | string)

Raises err again: an error table as pcall gives it, or a string. An error table keeps its original location and stack.

pcall(f: function, ...args) -> table

Calls f(...args) and catches what it raises: {"ok", result} when it returns, {"err", e} when it raises. e is an Error; when f raised a table, e is that table, with location and stack added.

local r = pcall(parse, text)
if(let {"err", local e} = r){
  print(e.message, "\n")
}

values

type(v) -> string

The type name of v: "null", "bool", "int", "double", "string", "table", "function", "thread" or "userdata". A table or userdata whose metatable has __type gets that value instead (or its result, when __type is a function called with v).

len(v: string | table) -> int

The length of a string in bytes, or the number of entries of a table (list elements and other keys alike); a metatable's __len function decides instead when there is one. Raises an error for other values.

string(v) -> string

v rendered as a string, through its __tostring metamethod when it has one.

to_int(v: int | float | string) -> int

v as an int: ints as they are, doubles truncated (saturating, NaN gives 0), strings parsed as decimal or "0x" hex digits with an optional sign. Raises an error for an invalid string or another type.

tables

append(t: table, v: any)

Sets t[len(t)] to v, adding v at the end of a list. As len counts every entry, use it on lists: on a table with other keys it does not add at the end of the list part (see list_push).

list_push(t: table, v: any)

Adds v at the end of the list part of t, keeping a null v as a slot (append and list literals stop at null).

remove(t: table, key) -> any

The value removed from t at key, or null. Removing a list index shifts the later elements down. Returns null when t is not a table.

keys(t: table) -> function

An iterator over the keys of t: list indices first, then the other keys in insertion order. The keys are a snapshot taken by the call. A slang/buffer iterates its indices. Returns null for anything else.

for(let local k in keys(t)){ print(k, "\n") }

values(t: table?) -> function

An iterator over the values of t, in the order of keys. A null t iterates nothing, a slang/buffer its elements; anything else raises an error.

entries(t: table?) -> function

An iterator over the {key, value} pairs of t, in the order of keys. A null t iterates nothing, a slang/buffer its {index, element} pairs; anything else raises an error.

for(let local e in entries(t)){ print(e[0], "=", e[1], "\n") }

concat(...values) -> string | table

When the first value is a string, all values rendered and joined into one string as print does. When it is a table, a new table with the lists of all the tables appended in order and their other keys copied (later tables win). Raises an error otherwise.

concat("a", 1, "b")   // "a1b"
concat({1, 2}, {3})   // {1, 2, 3}

set_raw(t: table, key, v: any)

Sets the value of t at key to v, without metamethods.

get_raw(t: table, key) -> any

The value of t at key, without metamethods.

type Error

type Error = {message: string, location?: {line: int, column: int, origin: string}, stack?: string}

What pcall catches.

message: string
the error's text
location?: {line: int, column: int, origin: string}
where it was raised
stack?: string
the stack traceback as text

type File

An open file, from open; type() of it is "file". It is closed when it is collected.

File:read(n?: int) -> string

The next n bytes, fewer at the end of the file, or the rest of the file when n is left out.

File:readBytes(n?: int) -> {int}

Like File.read, but a list of byte values (ints 0-255).

File:write(s: string)

Writes s.

File:writeBytes(bytes: {int})

Writes a list of byte values; each int is cut to its low 8 bits.

File:close()

Closes the file; closing it again does nothing. Reading or writing a closed file raises an error.
