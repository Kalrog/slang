slang/buffer

slang/buffer: typed memory. A buffer holds n values of one C type, a scalar or a struct, in memory slang indexes about as fast as a list and C reads without a copy (a buffer passed to slang/ffi is its memory).

local buffer = require("slang/buffer")
local samples = buffer.new("float", 44100)
for(local i = 0; i < len(samples); i = i + 1){
  samples[i] = math.sin(i * 0.05)
}
local points = buffer.new("Vector2", 100, rl.decls)
points[3].x = 10                       // a struct element is a view

Indexes count from 0, like lists, and are checked. b[i] of a scalar is a number; of a struct a pointer to the element, so b[i].x = 3 writes in place; b[i] = v converts v as slang/ffi does (a table for a struct). len(b) is the number of elements, == compares type and contents, and values, keys and entries iterate a buffer like a list.

Methods: b:size() (bytes), b:type(), b:slice(from, [to]) (shares the memory), b:copy(), b:fill(v), b:set(list or buffer, [at]), b:cast(type) (the same bytes as another type; a type value, from b:type() or ffi.type), b:to_list(), b:to_string() (the bytes), b:same(other) (the same memory), b:pointer().

Types are C names: scalars ("float", "double", "int", "uint8_t", "int32", ...) or, with declarations from ffi.cdef, structs ("Vector2").

buffer.new(t, n, decls)

new(type, n, [decls]) -> a buffer of n zeroed elements

buffer.from(src, t, decls)

from(list or string, type, [decls]) -> a buffer with the list's elements (numbers, or tables for structs), or with the bytes of a string

buffer.from_string(s)

from_string(s) -> a buffer of the bytes of s (uint8)

buffer.wrap(p, n, t, decls)

wrap(pointer, n, [type], [decls]) -> a buffer over n elements of memory C owns (mesh.vertices with vertex_count * 3 floats): the pointer's type, or type. It is valid as long as C keeps the memory.

buffer.is(v)

is(v) -> whether v is a buffer
