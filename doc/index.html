slang's library

crypto
crypto: the native binding of the parts of OpenSSL 3 (libcrypto) that web applications need.
globals
globals: the functions every slang program has without a require, built into the VM.
llhttp
llhttp: the native binding of llhttp, the HTTP/1 parser of Node.js.
slang/ast
slang/ast: building, checking and printing the syntax tree that the parser produces, quotes (+{...}) build and extensions return.
slang/async
slang/async: Futures, Streams and await on coroutines, driven by the uv event loop (the native uv module).
slang/buffer
slang/buffer: typed memory.
slang/build
slang/build: slang build, a program as one executable that runs without slang installed.
slang/bundle
slang/bundle: the files of a program built by slang build, built into the VM.
slang/bundle_tool
slang/bundle_tool: how slang build (slang/build) writes executables, built into the VM.
slang/codegen
slang/codegen: compiles AST nodes into function prototypes, tables that slang/vm's load_proto turns into functions.
slang/compiler
slang/compiler: the compiler driver.
slang/crypto
slang/crypto: the crypto native extension (OpenSSL) plus what web code builds from it: password hashes, random tokens, signed and sealed values.
slang/ctypes
slang/ctypes: C types and C memory, in every build: the native part of slang/ffi and slang/buffer, which most code uses instead (they take the names of C types where this module takes type values).
slang/doc
slang/doc: API documentation from the comments the code already has, as HTML: slang doc [-o dir] [file|dir...].
slang/encoding
slang/encoding: the byte encodings web code needs, built into the VM, one table per encoding with an encode and a decode.
slang/ffi
slang/ffi: calling C libraries without writing C.
slang/ffi_core
slang/ffi_core: calls to C through libffi, the native part of slang/ffi (which most code uses instead: it reads C declarations and makes these calls for you).
slang/format
slang/format: the formatter (slang fmt).
slang/grammar
slang/grammar: the slang grammar, built with slang/peg on top of a rule registry that lets programs extend and modify the parser at compile time.
slang/hash
slang/hash: checksums and digests, built into the VM.
slang/html
slang/html: HTML nodes that render to a string.
slang/http
slang/http: an HTTP/1.1 server and client on slang/async, parsing with llhttp (the llhttp native extension) and compressing with zlib.
slang/isolate
slang/isolate: parallelism without shared state, built into the VM.
slang/json
slang/json: encode and decode JSON.
slang/jwt
slang/jwt: JSON Web Tokens (RFC 7519) over slang/crypto.
slang/math
slang/math: numeric functions and constants, built into the VM.
slang/optimizer
slang/optimizer: constant folding on the AST, applied by the grammar to every parsed chunk.
slang/os
slang/os: files, the process and its environment, built into the VM.
slang/path
slang/path: slash-separated paths, as files and URLs use them (Go's path and path/filepath on Unix).
slang/peg
slang/peg: parser combinators in the style of petitparser (PEG: ordered choice, no ambiguity), the expression walker extensions add operators with, and the lossless tree that highlighting and formatting read.
slang/pkg
slang/pkg: packages: slang get, slang update [name...], slang deps.
slang/regex
slang/regex: regular expressions, built into the VM.
slang/sqlite
slang/sqlite: SQLite with an API that reads well, on the native sqlite extension.
slang/std
slang/std: global functions written in slang: module, run and the matcher protocol behind 'm patterns.
slang/string
slang/string: functions on byte strings, built into the VM.
slang/symbols
slang/symbols: what a file defines and uses, for the language server (hover, go to definition, references) and slang doc.
slang/table
slang/table: helpers over tables and lists: sorting, searching, inserting, slicing, and map, filter, fold.
slang/test
slang/test: a small test framework: groups of named tests, set up and torn down, run by slang test.
slang/thread
slang/thread: cooperative coroutines, built into the VM.
slang/time
slang/time: wall-clock time as milliseconds since the Unix epoch, in UTC, built into the VM.
slang/tls
slang/tls: TLS on libuv TCP, with the tls native extension (OpenSSL).
slang/utf8
slang/utf8: the characters of UTF-8 strings, built into the VM.
slang/web
slang/web: the application layer on slang/http: routes, middleware, request helpers, responses, static files, sessions, CSRF protection, WebSocket routes and a test client.
slang/webview
slang/webview: desktop windows whose content is a web page and whose logic is slang (macOS, WKWebView), in the style of Wails.
slang/ws
slang/ws: WebSockets (RFC 6455) on slang/async, both sides.
slang/zlib
slang/zlib: deflate and inflate (zlib) in the gzip, zlib and raw formats, at once or as a stream.
sqlite
sqlite: the native binding of SQLite, as thin as it is useful.
tls
tls: the native binding of OpenSSL 3's TLS (libssl) as an engine on memory buffers.
uv
uv: the native binding of libuv in the callback style of luv.
zlib
zlib: the native binding of zlib (deflate and inflate in the gzip, zlib and raw formats), at once or as a stream.

Extensions

slang/inline_test
slang/inline_test: tests next to the code they test, in the same file.
