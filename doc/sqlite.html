sqlite

sqlite: the native binding of SQLite, as thin as it is useful. Most code should use slang/sqlite, which builds the friendly API on it.

local sqlite = require("sqlite")
local db = sqlite.open("todos.db")  // or ":memory:"
db:exec("create table t(id integer primary key, name text)")
local st = db:prepare("insert into t(name) values (?)")
st:bind_all({"ada"}) st:step() st:reset()
local q = db:prepare("select * from t where id > ?")
q:bind(1, 0)
for(q:step()){ print(q:row().name, "\n") }

Values: null, bool (bound as 0/1), int, double, string (text; a blob column also comes back as a string). A column declared boolean (or bool) is read as true/false. A statement is linked to its database: closing the database finalizes its statements, and a finalized statement raises on use. Errors read "sqlite: ...".

m.open(path)

open(path) -> a sqlite.db; the file is created when missing, ":memory:" opens a database in memory. Raises when it cannot be opened.

m.version()

version() -> the version of the SQLite library

type sqlite.db

sqlite.db:exec(sql)

db:exec(sql) runs one or more statements, discarding any rows

sqlite.db:prepare(sql)

db:prepare(sql) -> a sqlite.stmt for the first statement in sql; raises when the text holds no statement

sqlite.db:close()

db:close() finalizes the statements and closes the database; raises while queries started with run_async are running

sqlite.db:is_open()

db:is_open() -> whether the database is still open

sqlite.db:changes()

db:changes() -> the number of rows changed by the last statement

sqlite.db:last_insert_rowid()

db:last_insert_rowid() -> the rowid of the last inserted row

type sqlite.stmt

sqlite.stmt:bind(i, value)

stmt:bind(i, value) -> stmt; binds parameter i (from 1) to value

sqlite.stmt:bind_all(values, count)

stmt:bind_all(values, [count]) -> stmt; binds the parameters in order. count (default len(values)) covers values after a null, which ends a list's length; it must equal the number of parameters.

sqlite.stmt:step()

stmt:step() -> true when a row is ready, false when the statement is done

sqlite.stmt:row()

stmt:row() -> {name: value, ...} of the current row

sqlite.stmt:values()

stmt:values() -> {value, ...} of the current row, in column order

sqlite.stmt:columns()

stmt:columns() -> the list of column names

sqlite.stmt:parameter_count()

stmt:parameter_count() -> the number of parameters

sqlite.stmt:reset()

stmt:reset() -> stmt, ready to run again with its bindings cleared

sqlite.stmt:finalize()

stmt:finalize() frees the statement; using it afterwards raises

sqlite.stmt:run_async(cb)

stmt:run_async(cb) runs the bound statement to the end on libuv's thread pool and calls cb(err, {rows, changes, last_insert_rowid}) from the loop (rows: a list of {name: value} tables). Until then the statement is busy: using it raises and the database cannot be closed.

sqlite.stmt:is_busy()

stmt:is_busy() -> whether a run_async query is still running it
