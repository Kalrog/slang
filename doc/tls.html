tls

tls: the native binding of OpenSSL 3's TLS (libssl) as an engine on memory buffers. It does no I/O: slang/tls moves the bytes between the engine and a libuv TCP handle, and most code should use slang/tls.

local tls = require("tls")
local ctx = tls.context({alpn: {"http/1.1"}})
local s = ctx:session("example.com")
s:handshake()          // false: it waits for the server
local out = s:take()   // bytes to send to the server

The system's trust store is OpenSSL's default (SSL_CERT_FILE and SSL_CERT_DIR override it), or else the first bundle found at the usual paths. Errors read "tls: ...".

contexts

tls.context(options?: ContextOptions) -> Context

A context; raises "tls: ..." for a certificate or key it cannot load.

certificates

tls.self_signed(names: {string}, days?: int) -> Certificate

A certificate for local development, valid for days (365), with an EC P-256 key.

local c = tls.self_signed({"localhost", "127.0.0.1"})
local ctx = tls.context({server: true, cert: c.cert, key: c.key})
names
host names or IP addresses; the first is the subject

tls.version() -> string

The OpenSSL version text.

type ContextOptions

type ContextOptions = {server?: bool, cert?: string, key?: string, ca?: string, verify?: bool, alpn?: {string}, min_version?: string}

The options of context. A verifying client needs the server's certificate valid for the host name; a verifying server asks the client for a certificate.

server?: bool
a server context (false by default)
cert?: string
PEM text of the certificate chain, leaf first; needed by a server
key?: string
PEM text of the certificate's private key; needed by a server
ca?: string
PEM text of the certificates to trust instead of the system's
verify?: bool
check the peer's certificate (a client does by default)
alpn?: {string}
protocol names to offer or accept, by preference
min_version?: string
"1.2" (the default) or "1.3"

type Context

Settings shared by many sessions: certificates, trust, ALPN.

Context:session(hostname?: string) -> Session

A client session for hostname (a host name or an IP address; needed when the context verifies), or a server session for a server context.

type Session

One TLS connection's state machine: bytes from the network go in with Session.feed, bytes for the network come out of Session.take.

Session:feed(bytes: string)

Hands the session bytes that arrived from the network.

Session:handshake() -> bool

Advances the handshake: true when it is done, false while it waits for the peer; raises when it fails (a certificate that does not verify, for one).

Session:read() -> string?

The plaintext decrypted so far ("" for none), or null once the peer closed the session (close_notify).

Session:write(plaintext: string)

Encrypts plaintext for Session.take; only after the handshake.

Session:take() -> string

The bytes to send to the network ("" for none); call it after every other method, which may all produce some.

Session:close()

Queues a close_notify for Session.take, when the handshake got that far.

Session:info() -> Info

What was negotiated so far; fields that are not known yet are null.
