slang/webview

slang/webview: desktop windows whose content is a web page and whose logic is slang (macOS, WKWebView), in the style of Wails.

local async = require("slang/async")
local webview = require("slang/webview")
async.main(func(){
  local win = webview.window({title: "Hello", html: "<h1>hi</h1>"})
  win:bind("add", func(a, b){ return a + b })  // page: await slang.call("add", 1, 2)
  await win.closed
})

The page gets a global slang object: slang.call(name, ...args) returns a Promise of what the function bound as name returns, slang.send(value) passes value to Window.on_message handlers, and slang.on(f) registers f for the values Window.send pushes. Values cross as JSON.

Opening a window makes slang/async's main loop wait on the window system and libuv together (async.set_driver), so servers, timers and files keep working while windows are open.

webview.window(options?: Options) -> Window

Opens a window. Raises when the native webview module cannot be loaded (it exists only on macOS).

type Options

type Options = {title?: string, width?: int, height?: int, resizable?: bool, debug?: bool, url?: string, html?: string, app?: any, path?: string}

What window shows and how. One of url, html and app says what to show. WebKit keeps no cookies for app://, so an app has no cookie sessions (it serves one user anyway).

title?: string
"slang" by default
width?: int
900 by default
height?: int
640 by default
resizable?: bool
true by default
debug?: bool
enables the Web Inspector
url?: string
a page to load
html?: string
markup to show
app?: any
a slang/web app, served to the window over app:// with no socket
path?: string
the first page of the app, "/" by default

type Window

A window. Its field closed is an async.Future that completes (with null) when the window closes.

Window:receive(text: string)

Handles a raw message from the page: a call to answer or a value for the Window.on_message handlers. Used internally; text that is not a JSON object is ignored.

Window:bind(name: string, f: function) -> Window

Makes the page's slang.call(name, ...args) call f(...args). The Promise resolves with f's result (f may return a Future, which is awaited) and rejects with the error message when f raises or nothing is bound as name. Returns the window, so calls chain.

Window:on_message(f: func(value: any)) -> Window

Calls f with each value the page sends with slang.send(value). An error in f is ignored. Returns the window.

Window:send(value)

Passes value to the page's slang.on(f) listeners; does nothing once the window is closed.

Window:navigate(url: string)

Loads url in the window.

Window:set_html(html: string)

Replaces the page with html.

Window:eval(js: string)

Runs JavaScript in the page; its result is not returned.

Window:set_title(t: string)

Sets the window's title.

Window:close()

Closes the window; its closed future completes.

Window:is_open() -> bool

Whether the window is still open.
