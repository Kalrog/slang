Slang is a scripting language in the family of Lua. Tables, closures, coroutines and pattern matching, with a parser written in slang that your programs can extend: new statements, new operators, whole dialects, as plain libraries.

familiar on day one

Lua's simplicity, with a few modern manners

One data structure, the table, for lists, records and objects. Functions are values and closures. On top: patterns that take values apart, try/catch that matches what was raised, defer, labeled loops, spread arguments.

grow the language

The grammar is a library

Slang's parser is written in slang, and a program can change it: an extension block adds statements, operators or whole sub-languages, for the rest of its file. Projects load extensions for all their files, and give file types their own dialect.

Everything in one small binary

slang build

One executable from a program, its modules and its assets. No C compiler needed.

slang fmt

An opinionated formatter that knows your extensions' syntax too.

slang test

Groups and tests, with JSON output for editors and CI.

slang doc

API docs from typed doc comments, like the ones on this site.

Editors

A language server, a VS Code extension and a debugger, built on the real parser.

Packages

Get slang

Slang builds from source with Zig 0.17. The binary carries its compiler and standard library; nothing else is needed at run time.

git clone https://github.com/Kalrog/slang
cd slang
make build            # bin/slang
make install          # /usr/local (or PREFIX=~/.local)
bin/slang run hello.slang
