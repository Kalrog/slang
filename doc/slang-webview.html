slang/webview

slang/webview: desktop windows whose content is a web page and whose logic is slang (macOS, WKWebView), in the style of Wails.

local webview = require("slang/webview")
async.main(func(){
  local win = webview.window({title: "Hello", html: "<h1>hi</h1>"})
  win:bind("add", func(a, b){ return a + b })    // await slang.call("add", 1, 2)
  await win.closed
})

webview.window(options) -> a window; options: title, width, height, resizable (true), debug (the Web Inspector), and what to show: url, html, or app, a slang/web app served to the window over the app:// scheme with no socket at all (path: the first page, "/"). WebKit keeps no cookies for app://, so such an app has no cookie sessions; it is one user's anyway.

A window:

win.closed                    Future, completes when the window closes
win:bind(name, f)             the page's slang.call(name, ...args)
                              returns a Promise of f(...args) (f may
                              return a Future; an error rejects it)
win:on_message(f)             f(value) for each slang.send(value)
win:send(value)               the page's slang.on(f) listeners get it
win:navigate(url)   win:set_html(html)   win:eval(js)
win:set_title(t)    win:close()          win:is_open()

Values cross as JSON. Opening a window makes slang/async's main loop wait on the window system and libuv together (async.set_driver), so servers, timers and files keep working while windows are open.
