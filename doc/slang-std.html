slang/std

slang/std: global functions written in slang: module, run and the matcher protocol behind 'm patterns. They are globals; nothing needs to require this module.

local point = module{
  func make(x, y){ return {x: x, y: y} }
}
local p = point.make(1, 2)
local big = run{ if(p.x > 0){ return "right" } return "left" }

module(mfunc: function) -> table

Runs mfunc (usually a block: module{ ... }) with a fresh table as its _ENV and returns that table, so every global defined inside ends up in it. While the block runs, names it does not define still read the enclosing globals; afterwards the table holds only its own definitions.

__match(m, v) -> any

The matcher protocol behind 'm patterns: calls the __match metamethod of m with (m, v). Its result decides: null means v does not match; anything else is what the rest of the pattern sees. Raises an error when m has no __match metamethod (strings, numbers, functions and the like never do).

run(rfunc: function) -> any

Calls rfunc and returns its result: run{ ... } evaluates a block as an expression.
