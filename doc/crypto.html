crypto

crypto: the native binding of the parts of OpenSSL 3 (libcrypto) that web applications need. Most code should use slang/crypto (and slang/jwt), which build on it.

local crypto = require("crypto")
crypto.hash("sha256", "abc")  // 32 raw bytes
crypto.hasher("sha256"):update("a"):update("bc"):digest()

Digests are OpenSSL names ("sha1", "sha256", "sha384", "sha512", "sha3-256", "md5", ...). Results are raw byte strings; slang/encoding makes hex or base64 of them. Errors are raised with OpenSSL's message.

hashes and MACs

m.hash(digest, data)

hash(digest, data) -> the raw digest of data

m.hmac(digest, key, data)

hmac(digest, key, data) -> the raw HMAC of data under key

m.random_bytes(n)

random_bytes(n) -> n cryptographically random bytes, n from 0 to 1048576

m.equal(a, b)

equal(a, b) -> whether the strings are equal, in time that depends only on their lengths (for comparing MACs and tokens)

m.hasher(digest)

hasher(digest) -> a crypto.hasher: update(data) as often as needed, then digest() once

key derivation

m.pbkdf2(digest, password, salt, iterations, length)

pbkdf2(digest, password, salt, iterations, length) -> length bytes (1 to 4096) derived with PBKDF2-HMAC; at least one iteration

m.scrypt(password, salt, n, r, p, length)

scrypt(password, salt, n, r, p, length) -> length bytes (1 to 4096) derived with scrypt; n a power of two above 1, r and p positive

m.pbkdf2_async(digest, password, salt, iterations, length, cb)

pbkdf2_async(digest, password, salt, iterations, length, cb) runs pbkdf2 on libuv's thread pool and calls cb(err, bytes) from the loop

m.scrypt_async(password, salt, n, r, p, length, cb)

scrypt_async(password, salt, n, r, p, length, cb) runs scrypt on libuv's thread pool and calls cb(err, bytes) from the loop

encryption

m.encrypt(cipher, key, iv, plaintext, aad)

encrypt(cipher, key, iv, plaintext, [aad]) -> the ciphertext followed by the 16-byte tag. cipher is an AEAD: "aes-128-gcm", "aes-256-gcm" or "chacha20-poly1305"; key as long as the cipher needs, iv 8 to 64 bytes (12 is usual); aad is authenticated but not encrypted.

m.decrypt(cipher, key, iv, sealed, aad)

decrypt(cipher, key, iv, sealed, [aad]) -> the plaintext, or null when the data, the aad, the key or the iv do not match the tag

keys

m.private_key(pem, passphrase)

private_key(pem, [passphrase]) -> a crypto.key from a PEM private key

m.public_key(pem)

public_key(pem) -> a crypto.key from a PEM public key ("BEGIN PUBLIC KEY")

m.generate_key(type, param)

generate_key(type, [param]) -> a new private crypto.key: ("rsa", [bits]) with bits 1024 to 16384 (2048), ("ec", [curve]) with curve "P-256" by default, or ("ed25519")

version

m.version()

version() -> the OpenSSL version text

type crypto.hasher

crypto.hasher:update(data)

hasher:update(data) -> hasher, with data added

crypto.hasher:digest()

hasher:digest() -> the raw digest; the hasher raises on further use

type crypto.key

crypto.key:sign(digest, data, options)

key:sign(digest, data, [options]) -> the signature of data; needs a private key. options: {padding: "pss"} for RSA-PSS (salt as long as the digest), {encoding: "raw"} for ECDSA signatures as r || s (the JWT form) instead of DER. Ed25519 ignores the digest (pass null).

crypto.key:verify(digest, data, signature, options)

key:verify(digest, data, signature, [options]) -> whether signature is a valid signature of data; options as for sign

crypto.key:type()

key:type() -> "rsa", "rsa-pss", "ec", "ed25519", "ed448" or "other"

crypto.key:bits()

key:bits() -> the size of the key in bits

crypto.key:is_private()

key:is_private() -> whether the key holds the private half

crypto.key:public_pem()

key:public_pem() -> the public key as PEM ("BEGIN PUBLIC KEY")

crypto.key:private_pem()

key:private_pem() -> the private key as unencrypted PKCS#8 PEM; raises for a public key

crypto.key:public_key()

key:public_key() -> the public half as a crypto.key of its own
