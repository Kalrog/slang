The standard library

Every module that ships with slang, generated from the doc comments in its source by slang doc. Load a module with require: local str = require("slang/string"). The globals (print, len, pcall, ...) need no require.

Signatures are typed in the docs' own notation: name?: T is optional, {T} a list, {[K]: V} a map, {a: T} a table with fields, A | B either. Slang itself has no types; these are for readers and editors. New to the language? Start with the tour.
