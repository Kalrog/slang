slang/math

slang/math: numeric functions and constants, built into the VM.

local math = require("slang/math")
math.sqrt(2)                // 1.4142135623730951
math.floor(2.7)             // 2.0, a double
to_int(math.floor(2.7))     // 2
math.max(3, 7, 5)           // 7, still an int

Unless noted the functions take an int or a double and return a double; use to_int for an int. Angles are in radians.

math.pi

The constant pi, 3.14159...

math.e

The constant e, 2.71828...

math.inf

Positive infinity, a double.

math.nan

A NaN, a double; use is_nan to test for one (NaN == NaN is false).

math.max_int

The largest int, 2^63 - 1.

math.min_int

The smallest int, -2^63.

rounding

math.round(x: int | float) -> float

x rounded to the nearest whole number, halves away from zero.

math.floor(x: int | float) -> float

The largest whole number not above x.

math.ceil(x: int | float) -> float

The smallest whole number not below x.

math.abs(x: int | float) -> int | float

The absolute value of x; an int for an int.

math.min(...xs: int | float) -> int | float

The smallest of the numbers, as given (an int stays an int); the double infinity without arguments. Raises an error for a non-number.

math.max(...xs: int | float) -> int | float

The largest of the numbers, as given (an int stays an int); the double minus infinity without arguments. Raises an error for a non-number.

math.trunc(x: int | float) -> float

x without its fraction, toward zero.

math.sign(x: int | float) -> int | float

-1, 0 or 1 as x is negative, zero or positive; an int for an int.

math.clamp(x: int | float, lo: int | float, hi: int | float) -> int | float

x limited to lo..hi; an int when all three are ints.

math.lerp(a: int | float, b: int | float, t: int | float) -> float

The value t of the way from a to b: a + (b - a) * t.

math.is_nan(x) -> bool

Whether x is a NaN.

math.is_inf(x) -> bool

Whether x is an infinity (either sign).

random

math.random(lo?: int | float, hi?: int | float) -> float

A random double from lo (0 by default) up to hi (1 by default).

math.random_int(lo: int, hi: int) -> int

A random int from lo up to and including hi.

math.seed(n: int)

Starts the random numbers over from n, so a program repeats the same ones; without it they differ every run.
