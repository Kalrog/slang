crypto

crypto: the native binding of the parts of OpenSSL 3 (libcrypto) that web applications need. Most code should use slang/crypto (and slang/jwt), which build on it.

local crypto = require("crypto")
crypto.hash("sha256", "abc")  // 32 raw bytes
crypto.hasher("sha256"):update("a"):update("bc"):digest()

Digests are OpenSSL names ("sha1", "sha256", "sha384", "sha512", "sha3-256", "md5", ...). Results are raw byte strings; slang/encoding makes hex or base64 of them. Errors are raised with OpenSSL's message.

hashes and MACs

crypto.hash(digest: string, data: string) -> string

The raw digest of data.

crypto.hmac(digest: string, key: string, data: string) -> string

The raw HMAC of data under key.

crypto.random_bytes(n: int) -> string

n cryptographically random bytes, n from 0 to 1048576.

crypto.equal(a: string, b: string) -> bool

Whether the strings are equal, in time that depends only on their lengths (for comparing MACs and tokens).

crypto.hasher(digest: string) -> Hasher

A hasher for incremental hashing.

key derivation

crypto.pbkdf2(digest: string, password: string, salt: string, iterations: int, length: int) -> string

length bytes (1 to 4096) derived with PBKDF2-HMAC; at least one iteration.

crypto.scrypt(password: string, salt: string, n: int, r: int, p: int, length: int) -> string

length bytes (1 to 4096) derived with scrypt; n a power of two above 1, r and p positive.

crypto.pbkdf2_async(digest: string, password: string, salt: string, iterations: int, length: int, cb: func(err: string?, bytes: string?))

Runs pbkdf2 on libuv's thread pool and calls cb from the loop.

crypto.scrypt_async(password: string, salt: string, n: int, r: int, p: int, length: int, cb: func(err: string?, bytes: string?))

Runs scrypt on libuv's thread pool and calls cb from the loop.

encryption

crypto.encrypt(cipher: string, key: string, iv: string, plaintext: string, aad?: string) -> string

The ciphertext followed by the 16-byte tag.

cipher
an AEAD: "aes-128-gcm", "aes-256-gcm" or "chacha20-poly1305"
key
as long as the cipher needs (32 bytes for aes-256-gcm)
iv
8 to 64 bytes (12 is usual); never reuse one with the same key
aad
data that is authenticated but not encrypted

crypto.decrypt(cipher: string, key: string, iv: string, sealed: string, aad?: string) -> string?

The plaintext of what encrypt made, or null when the data, the aad, the key or the iv do not match the tag.

keys

crypto.private_key(pem: string, passphrase?: string) -> Key

A key from a PEM private key (encrypted ones need the passphrase).

crypto.public_key(pem: string) -> Key

A key from a PEM public key ("BEGIN PUBLIC KEY").

crypto.generate_key(type: string, param?: int | string) -> Key

A new private key: ("rsa", [bits]) with bits 1024 to 16384 (2048 by default), ("ec", [curve]) with curve "P-256" by default, or ("ed25519").

local key = crypto.generate_key("ec", "P-384")

version

crypto.version() -> string

The OpenSSL version text.

type Hasher

A digest computed piece by piece: Hasher.update as often as needed, then Hasher.digest once.

Hasher:update(data: string) -> Hasher

Adds data; returns the hasher, so calls chain.

Hasher:digest() -> string

The raw digest; the hasher raises on further use.

type Key

A private or public key (RSA, EC, Ed25519, ...) from private_key, public_key or generate_key; type(key) is "crypto.key".

Key:sign(digest: string?, data: string, options?: SignOptions) -> string

The signature of data; needs a private key. Ed25519 ignores the digest (pass null).

Key:verify(digest: string?, data: string, signature: string, options?: SignOptions) -> bool

Whether signature is a valid signature of data; options as for Key.sign.

Key:type() -> string

"rsa", "rsa-pss", "ec", "ed25519", "ed448" or "other".

Key:bits() -> int

The size of the key in bits (521 for a P-521 key).

Key:is_private() -> bool

Whether the key holds the private half.

Key:public_pem() -> string

The public key as PEM ("BEGIN PUBLIC KEY").

Key:private_pem() -> string

The private key as unencrypted PKCS#8 PEM; raises for a public key.

Key:public_key() -> Key

The public half as a key of its own.

type SignOptions

type SignOptions = {padding?: string, encoding?: string}

How Key.sign and Key.verify work beyond the key's own algorithm.

padding?: string
"pss" for RSA-PSS (salt as long as the digest)
encoding?: string
"raw" for ECDSA signatures as r || s (JWT's) instead of DER
