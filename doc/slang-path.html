slang/path

slang/path: slash-separated paths, as files and URLs use them (Go's path and path/filepath on Unix). Nothing here touches the disk except abs, which reads the current directory.

local path = require("slang/path")
path.join("a", "b/../c", "d.txt")   // "a/c/d.txt"
path.dir("src/main.slang")          // "src"
path.base("src/main.slang")         // "main.slang"
path.ext("src/main.slang")          // ".slang"
path.rel("/a/b", "/a/c/d")          // "../c/d"

path.clean(p: string) -> string

The shortest path naming the same file: repeated slashes become one, "." elements go, and ".." removes the element before it where there is one (a rooted path starts over at "/"). The empty path is ".".

path.clean("a//b/./../c/")   // "a/c"

path.join(...parts: string) -> string

The non-empty parts joined with "/" and cleaned; "" when all are empty.

path.join("a", "", "/b", "c/")   // "a/b/c"

path.split(p: string) -> {string}

{dir, file}: p split after its last slash; dir keeps the slash, so concat(dir, file) is p.

path.split("a/b/c.txt")   // {"a/b/", "c.txt"}

path.base(p: string) -> string

The last element of p, without trailing slashes; "." for "" and "/" for a path of slashes only.

path.dir(p: string) -> string

All of p but its last element, cleaned: "." when there is no slash.

path.dir("/a/b")   // "/a"

path.ext(p: string) -> string

The extension of the last element of p, from its last "." on; "" when it has none.

path.is_abs(p: string) -> bool

Whether p starts at the root.

path.abs(p: string) -> string

p made absolute against the current directory, cleaned.

path.rel(from: string, to: string) -> string

A relative path that leads from the directory from to to, so that join(from, rel(from, to)) is clean(to). Raises when one is absolute and the other is not, or when from climbs above to with "..".

path.rel("a/b", "a/c/d")   // "../c/d"
