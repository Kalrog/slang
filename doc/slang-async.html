slang/async

slang/async: Futures, Streams and await on coroutines, driven by the uv event loop (the native uv module). Callback style and await style mix:

local async = require("slang/async")
async.main(func(){
  local conn = async.await(async.connect("127.0.0.1", 8080))
  async.await(async.write(conn, "hello\n"))
  local reader = async.reader(conn)
  for(true){
    local r = async.await(reader:next())
    if(r.done){ break }
    print(r.value)
  }
})

The extension extensions/async adds async func, await and await for on top of this module.

A Future completes once, with a value or an error (any value; errors raised inside async functions are the error tables pcall produces). A Stream is a sequence of values ending with done or an error; its next() gives the next Event as a Future, listen() consumes it with a callback. A Completer makes a Future, a Controller a Stream.

await must be called from a coroutine started by run or main (an "async function"). It registers a waiter that reschedules the coroutine and yields; a completed Future returns immediately without yielding. Waiters run from the loop (a zero timer), never inside the code that completed the Future, so completing a Future never re-enters the completer.

Handles (TCP connections, pipes, timers) are the native uv module's; connect, serve and reader turn them into Futures and Streams.

futures

async.completer() -> Completer

A pending Future and the functions that settle it.

local c = async.completer()
timer:start(100, 0, func(){ c.complete("late") })
return c.future

async.value(v) -> Future

A Future already completed with v.

async.failed(e) -> Future

A Future already failed with e. Unless something awaits or catches it, main reports it as unhandled.

async.wrap(start: func(cb: func(err: any, value: any))) -> Future

Turns a callback-style operation into a Future: start(cb) begins it, and cb has the uv shape cb(err, value). The future fails with err (when not null) or completes with value; an error start raises fails it too.

local f = async.wrap(func(cb){ handle:write(data, cb) })

async.all(futures: {Future}) -> Future

A Future of the list of the futures' values, in their order; it fails with the first error. An empty list gives an empty list at once.

async.race(futures: {Future}) -> Future

Settles like the first of the futures to settle; the others are marked handled and their results dropped. An empty list never settles.

async.timeout(f: Future, ms: int, message?: string) -> Future

A Future of f's value (or error), failing with message instead when f takes longer than ms milliseconds. f itself goes on; its late result is dropped. An error keeps only its message through raise, so tell a timeout by the message you chose.

message
"timed out after <ms> ms" by default

await and run

async.await(f: Future)

Waits for f, suspending the async function, and returns its value or raises its error. Raises when f is not a Future or when called outside an async function (run, main). A completed f returns at once.

returns
the value of f

async.run(f: function) -> Future

Runs f as an async function: in a coroutine that may await. It starts at once and runs until its first await. The future completes with f's return value or fails with its error.

async.sleep(ms: int) -> Future

Completes (with null) after ms milliseconds.

async.set_driver(step?: func(): bool)

Replaces how main waits for events: step() handles one batch and says whether there is more to do. null restores libuv's run("once"). For GUI extensions (slang/webview) that wait on a window system and libuv together.

async.main(f: function)

Runs f as an async function and drives the event loop until it finishes; the program's entry point. Raises f's error, or when the loop runs dry while f still waits. Failed futures nobody awaited or caught are printed as "async: unhandled error in a future".

returns
the value of f

streams

async.controller(options?: {high_water?: int}) -> Controller

A Stream fed by add(), with a buffer for values no one has read yet.

local c = async.controller()
c.add("a")
c.close()
async.await(c.stream:collect())   // {"a"}
options
high_water, the buffered values that call on_pause (16)

async.pull(next_value: func(): any) -> Stream

A Stream that reads only when asked: each next() calls next_value(), which returns the next value, null at the end, or a Future of either; an error it raises (or its Future's) ends the stream with that error. Nothing is read ahead, so a slow reader slows the source (a file sent to a slow client is not read into memory first).

local n = 0
local s = async.pull(func(){ n = n + 1  return n <= 3 and n or null })

async.iterator(s: Stream) -> func(): any

A function that awaits and returns the stream's next value, or null at the end; what await for loops over. Call it in an async function. A for-in loop stops at the first null, so a null value in the stream ends the loop early.

tcp adapters

async.resolve(host: string, port: int, family?: string) -> Future

A Future of the list of Addresses host resolves to.

family
"ipv4" or "ipv6" to resolve to that family only

async.connect(host: string, port: int) -> Future

A Future of a connected uv.tcp handle. A host name is resolved first and its addresses tried in order; the future fails with the last error.

async.write(handle, data: string) -> Future

Writes data to a uv stream handle (TCP, pipe, TLS); completes when it is written.

async.shutdown(handle) -> Future

Ends the writing side of a uv stream handle once pending writes are done.

async.close(handle) -> Future

Closes a uv handle; completes when it is closed.

async.reader(handle, options?: {high_water?: int}) -> Stream

A Stream of the string chunks read from a uv stream handle, ending when the other side does. Reading pauses when the consumer falls behind and resumes when it catches up.

options
as for controller

async.serve(host: string, port: int, options?: {backlog?: int, high_water?: int}) -> Listener

Listens on host:port. Raises when it cannot bind.

port
0 picks a free port
options
backlog, pending connections (128); high_water: controller

files

async.fs

The file system on libuv's thread pool; every function returns a Future. Errors read like "ENOENT: no such file or directory, read_file 'x'".

fs.read_file(path) -> the contents    fs.write_file(path, data)
fs.append_file(path, data)            fs.exists(path) -> bool
fs.stat(path) -> {size, mode, mtime, atime, ctime, is_file, is_dir}
fs.list_dir(path) -> list of {name, type}   (type "file", "dir", ...)
fs.remove(path)   fs.mkdir(path)   fs.rmdir(path)   fs.rename(from, to)
fs.open(path, flags) -> fd   (flags as fopen: "r", "w", "a", "r+", ...)
fs.read(fd, length, offset) -> data ("" at the end; offset null reads on)
fs.write(fd, data, offset) -> bytes written   fs.close(fd)
fs.read_stream(path, {chunk_size, start, length}) -> a Stream of the file, read on demand

In a program built by slang build, a relative path that names a bundled file or directory is read from the bundle (read_file, stat, list_dir, exists, read_stream; see slang/bundle); the rest is the disk's.

local text = async.await(async.fs.read_file("notes.txt"))

signals

async.on_signal(name: string, f: func(name: string))

Runs f(name) each time the process gets the signal ("SIGINT", "SIGTERM", ...). The handle does not keep the loop running; stop() or close() it when done.

returns
the uv.signal handle

processes

async.spawn(file: string, args?: {string}, options?: table) -> Process

Starts a program. Raises when it cannot be started. options are as for uv.spawn (cwd, env, detached, stdio), except that a stdio entry "pipe" makes a pipe. Without stdio the child inherits fds 0, 1 and 2.

local p = async.spawn("sleep", {"1"})
local r = async.await(p.exit)   // {status: 0}
args
the arguments, without the program itself

async.exec(file: string, args?: {string}, options?: table) -> Future

Runs a program to the end and collects its output: a Future of {status, signal, stdout, stderr}. It fails when the program cannot be started.

local r = async.await(async.exec("git", {"status", "--short"}))
print(r.status, r.stdout)
options
input (written to stdin, else empty); cwd and env: spawn

type Future

The result of an operation that finishes later: it completes once, with a value or an error. await it in an async function, or chain Future.then and Future.catch. A failed Future nobody awaits or catches is reported by main.

Future:is_done() -> bool

Whether the future has completed or failed.

Future:then(on_value?: func(value: any): any, on_error?: func(error: any): any) -> Future

A Future of what the handler returns; a handler may return a Future, which the result then follows. Without on_error the error propagates to the returned future; an error the handler raises fails it.

Future:catch(on_error: func(error: any): any) -> Future

then(null, on_error): a Future of f's value, or of what on_error returns for its error.

type Completer

type Completer = {future: Future, complete: func(value: any), fail: func(error: any)}

The making side of a Future: call complete or fail once (a second call raises "the future is already ...").

future: Future
complete: func(value: any)
fail: func(error: any)

type Stream

A sequence of values that ends with done or an error. Read it one way: Stream.next (or await for), Stream.listen or Stream.collect; a second reader raises "the stream is already being read".

Stream:next() -> Future

A Future of the next Event; it fails with the stream's error. One next() at a time; raises while another is pending or with a listener.

Stream:listen(cb: func(err: any, value: any)) -> Stream

Reads the stream with a callback: cb(null, value) for each value, then cb(null, null) at the end or cb(err, null) on an error. Returns the stream.

Stream:collect() -> Future

A Future of the list of all the values; it fails with the stream's error.

Stream:next() -> Future

Calls the source once and gives a Future of the next Event.

Stream:collect() -> Future

A Future of the list of all the values.

Stream:listen(cb: func(err: any, value: any)) -> Stream

Reads the stream with a callback, as Stream.listen does.

type Event

type Event = {value?: any, done?: bool}

What Stream.next gives: {value: v}, or {done: true} at the end.

value?: any
done?: bool

type Controller

type Controller = {stream: Stream, add: func(value: any), close: func(), fail: func(error: any), on_pause?: func(), on_resume?: func()}

The writing side of a Stream. add raises once the stream is closed; close and fail after the end do nothing.

stream: Stream
add: func(value: any)
close: func()
fail: func(error: any)
on_pause?: func()
called when the buffer reaches the high-water mark: pause
on_resume?: func()
called when a reader has drained the buffer below it again

type Process

type Process = {process: any, pid: int, stdin?: any, stdout?: any, stderr?: any, pipes: {[int]: any}, exit: Future, kill: func(sig?: string | int)}

A started program.

pid: int

the uv.pipe for fd 0 when stdio has "pipe" there
stdout?: any
the uv.pipe for fd 1, likewise
stderr?: any

sends a signal, a number or a name ("SIGTERM" by default)
