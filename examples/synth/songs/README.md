# Songs

Song files for the synth (see `../song.slang` for the format) and the MIDI
files they play. All the pieces are in the public domain, and so are these
editions of them: they come from the [Mutopia Project](https://www.mutopiaproject.org),
whose typesetters placed them in the public domain.

| file | piece | edition |
| ---- | ----- | ------- |
| `bach_prelude.mid` | J. S. Bach, Cello Suite No. 1 in G major, BWV 1007: Prelude | Mutopia no. 517 (`bwv1007.mid`), from Schirmer, 1916; typeset by Andreas Scherer, public domain |
| `grieg_mountain_king.mid` | E. Grieg, "In the Hall of the Mountain King" (Peer Gynt Suite No. 1, Op. 46), piano | Mutopia no. 1888, from The University Society, 1918; typeset by Coyau, public domain |
| `bach_invention8.mid` | J. S. Bach, Invention No. 8 in F major, BWV 779 | Mutopia no. 61 (`bach-invention-08.mid`), from the Bach-Gesellschaft; typeset by Allen Garvin, public domain |
| `bach_brandenburg2_1.mid` | J. S. Bach, Brandenburg Concerto No. 2 in F major, BWV 1047: I. Allegro | Mutopia no. 1680 (`score.mid`), from the Bach-Gesellschaft vol. 19, 1871; typeset by Andy Vaught, public domain |

The MIDI files are as Mutopia publishes them, only renamed.
