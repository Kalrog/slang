slang/ctypes

slang/ctypes: C types and C memory, in every build: the native part of slang/ffi and slang/buffer, which most code uses instead (they take the names of C types where this module takes type values).

local ct = __PACKAGES.preloaded["slang/ctypes"][1]
local v2 = ct.struct("Vector2")
ct.define(v2, {{"x", ct.primitive("float")}, {"y", ct.primitive("float")}})
local p = ct.new(v2)
p.x = 3
ct.value(p)                            // {x: 3.0, y: 0.0}

Types live as long as the program. Memory is a Pointer (an address, indexed like C, unchecked) or a Buffer (an address with a length, checked; see slang/buffer). Values convert to C as slang/ffi describes: numbers and bools for arithmetic types, a string for const char *, a table for a struct (fields by name or position).

ctypes.primitive(name: string) -> Type

A scalar type: void, bool, char (an int8 whose arrays are strings), int8..int64, uint8..uint64, float, double, pointer (void *) or string (const char *); raises for another name.

ctypes.pointer(target?: Type) -> Type

The type of a pointer to target (null: void *).

ctypes.array(elem: Type, n: int) -> Type

The type of n elems in a row (a struct field).

ctypes.struct(name: string) -> Type

A struct type, opaque (without a size) until define gives its fields.

ctypes.define(struct_type: Type, fields: {{any}})

Gives a struct its fields, laid out by C's rules.

fields
{name, type, [default]} per field; default fills a field left out

ctypes.sizeof(type: Type) -> int

Its size in bytes.

ctypes.offsetof(type: Type, field: string) -> int

The offset of a struct field in bytes.

ctypes.type_name(type: Type) -> string

Its name as messages show it ("Vector2 *").

ctypes.new(type: Type, n?: int) -> Pointer

A pointer to n (1 by default) zeroed values the collector frees once nothing points into them.

ctypes.cast(pointer: Pointer | int, type?: Type) -> Pointer

The same address as a pointer to type (null: void *); an int is taken as an address.

ctypes.offset(pointer: Pointer, n: int) -> Pointer

The pointer n elements further (bytes for a void pointer).

ctypes.address(pointer: Pointer?) -> int

The address as an int (0 for null).

ctypes.string(pointer: Pointer?, len?: int) -> string?

The zero-terminated C string at pointer, or len bytes; null for null.

ctypes.value(pointer: Pointer) -> any

The value pointed to, copied (a struct as a table); raises for a void pointer.

ctypes.buffer(type: Type, n: int) -> Buffer

A buffer of n zeroed elements.

ctypes.buffer_from(type: Type, src: {any} | string) -> Buffer

A buffer of the list's elements, or of the string's bytes (a whole number of elements).

ctypes.wrap(pointer: Pointer, n: int, type?: Type) -> Buffer

A buffer over n elements of C's memory at pointer, without a copy: of the pointer's type, or of type (needed for a void pointer).

ctypes.is_buffer(v) -> bool

Whether v is a buffer.

type Type

A C type: a scalar, a pointer, an array or a struct.

type Pointer

An address and the type it points to (none for void *). p[i] and p.field read and write like C; an element or field that is a struct is a pointer again. Pointers are == when their addresses are.

type Buffer

An address, an element type and a length; indexes are checked. Its methods are slang/buffer's.
