slang/json

slang/json: encode and decode JSON.

decode(text, origin) -> value: objects become tables with string keys, arrays become lists, null stays null (so a null member is an absent key). encode(value, options) -> text: tables whose keys are 0..n-1 (or marked with json.array) become arrays, other tables objects with string keys; {indent: " "} pretty-prints. Functions and other values are errors. json.null encodes as null where a value must be present (a table member set to null is absent): {result: json.null} -> {"result":null}.
